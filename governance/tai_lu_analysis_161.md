# PATCH-161 财太露原典拆解 PASS/UNKNOWN-PENDING 封板

## 原典(子平真诠·论财)
"财喜根深, 不宜太露。透一位不为之露, 太多则露矣。
然而财旺生官, 露亦不忌。葛参政命壬申壬子戊午乙卯, 岂非财露? 惟其生官, 所以不忌也。"

## 裁决链
财透一位 -> NOT露
财透过多 -> 原典称露(机器阈值未授权)
露 + 财旺生官 -> 露亦不忌
太露 -> 无充分原子条件无歧义机器化 -> UNKNOWN/PENDING

## 关键修正
- 禁以"无根+未生官"直接定义太露(无根=浮财是后注, 非沈孝瞻原文)
- 露 ≠ 忌: 财旺生官则露不忌
- 禁将财太露塞入blocked(会抹掉生官解露反例)
