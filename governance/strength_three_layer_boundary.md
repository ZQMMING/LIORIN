# 强弱引擎 三层判定边界 + 百分比特例标记规范

版本: v1.0
状态: FROZEN / 后续所有规则与 query 必须遵守

## 一、三层判定边界

### 主层（大多数情况，默认）
- 布尔 + 多态枚举 + 多维拓扑
- 事实在不在（成党/不成党、透/不透）
- 有序枚举（HEAVY > LIGHT > NONE、得令/失令）
- 已授权维度上的有序比较
- 不编分数、不设权重、不汇总成全局强弱

### 特例层（少数核心，需严格准入）
- 比重 / 百分比
- 仅当问题本质是连续程度，布尔和枚举都够不着时
- 例：从化格化得纯不纯、两神成象纯度、两支枚举同阶仍要分谁压谁

## 二、百分比准入三条件（必须同时满足）
1. 问题本质是连续程度，非"在不在/高一级低一级"
2. 枚举"两停"判不了，原典要求进一步分轻重
3. 百分比锚定客观结构（四柱位置/同党个数），非自编权重

## 三、百分比红线（即使在特例层也不破）
- 不把百分比汇总成"日主旺衰总分"（封掉的 Strength Resolver）
- 百分比只解决单个局部问题，不跨问题加总
- 原典没给程度的，不编阈值

## 四、百分比标记规范（强约束）

任何一处使用百分比/比重/除法比例，必须同时满足：

1. **注释打标**：行首注释 `# PCT-MARK:`，格式：
   ```
   # PCT-MARK: <局部问题> | 锚定=<客观结构> | 为何枚举不够=<理由> | revisit=<若错改这里>
   ```
2. **变量命名**：以 `pct_` 开头
3. **grep 可定位**：全仓 `grep "PCT-MARK" engines/` 必须能列出全部百分比点
4. **不嵌套**：一处百分比只服务一个局部判断，不被其他判断复用加总
5. **consumer_contract**：若 percentage 需放行，须在此显式加白名单并注明对应 PCT-MARK
