## 〇、准神规则（最高裁决规则，v1.6新增）

**《滴天髓》京图撰+刘基原注本（简称刘本/DTS）是唯一准神。** 余五书全是旁参。

| 规则 | 内容 |
|---|---|
| 准神唯一 | 凡旺衰、格局、从格、调候、病药、用神之义理之争，以刘本原文为最终裁决 |
| 余书降位 | 余五书主张与刘本相左时一律以刘本为准，其"重点取材"标注统一视为旁参 |
| 教义归位 | 某主张属哪部经典就挂哪部名下，禁止把余书专有义挂到刘本名下 |
| 旁参不废 | 余书内容照切、照入库，只是不得越过刘本作最终依据 |
| 工程例外 | 刘本未涉及的操作事项（ID/目录/流程/覆盖率/验证方法）不适用准神规则 |

### 准神归属三档（每条切片必填）

| 档位 | 含义 | 转jsonl映射 |
|---|---|---|
| **准** | 原文出自DTS刘本，或刘本明确主张此说 | authority=primary |
| **旁参** | 原文出自余五书，刘本未反对或未涉及 | authority=support |
| **被DTS否决** | 原文主张与刘本相左（见下方判定标准） | authority=vetoed |

### "与刘本相左"判定标准（满足任一即视为相左）

| 条件 | 说明 | 示例 |
|---|---|---|
| 结论相反 | 同一议题，他书结论与刘本方向相反 | 刘本"五阳从气不从势"，他书从格五分法 |
| 条件相反 | 同一规则，他书条件与刘本矛盾 | 刘本"只看月令是死法"，他书"月令为第一判据" |
| 优先级相反 | 他书设定优先级与刘本冲突 | 穷通"调候＞格局＞旺衰"，刘本以中和为归 |
| 概念专有 | 他书专有概念，刘本无此概念 | 子平"月劫格" |
| 出处错误 | 本属刘本被误挂他书，或本属他书被误挂刘本 | "甲木参天"本属DTS天干章被误挂QTBJ |

**判定要求：**
- 拿不准的，标"待确认"进问题清单，不要硬判
- 判为"被DTS否决"的，必须在备注记录：冲突对象（哪条刘本切片）、冲突类型、判定理由

## 二、子代理分工原则

**你负责什么，就只切什么。不要越界。**

- 不要切你分配范围之外的概念
- 不要替其他子代理补漏
- 不要改其他子代理已经写好的文件
- 发现问题 → 记录在 `_问题清单.md`，不要自己改

## 三、七步切片法（v1.6升级，必须严格执行）

```
第一步：概念定义
  → 明确你要切什么概念，列出所有古代表达/同义词/异体字
  → 例："得令"的古代表达 = [得令, 当令, 月令为某, 司令, 秉令]

第二步：AI广搜
  → 用所有表达式去六部原著里捞候选，宁多勿漏
  → 用 Grep 工具在六部底本里搜关键词

第三步：人工粗筛
  → 按篇章标题和上下文快速排除明显无关的候选
  → 粗筛不精读，只看上下文是否在讲命理规则

第四步：原著核对
  → 每条候选回原著看完整上下文
  → 确认是不是真的在表达你要的语义
  → 字符命中≠语义命中，必须看上下文

第五步：准神归属检验（v1.6新增，必须做）
  → 这条切片到底是刘本说的，还是余书说的？
  → 原文出自DTS → 准神归属=准
  → 原文出自余书 → 准神归属=旁参
  → 主张与刘本相左 → 准神归属=被DTS否决，备注记冲突
  → 拿不准 → 标"待确认"进问题清单，不要硬判

第六步：分型检验
  → 规则型：四问齐全（对象/关系/条件/结果）→ 可直接转工程
  → 原则型：四问不全但语义明确 → 标为"原则"

第七步：MD成文
  → 按v1.6统一模板写MD切片
  → 文件命名：`[DOMAIN]_[CONCEPT]_[序号].md`
  → 例：`FOUNDATION_RELATION_GAN_HE_001.md`
```

## 五、切片铁律（违反即废片）

1. **原文优先**：一切以原著原文为准，不采今人推测
2. **准神归位**：某主张属哪部经典就挂哪部名下，禁止把余书教义挂到刘本名下
3. **DTS版本绝对不能错**：DTS只用京图撰+刘基原注，绝对不能混入任铁樵《滴天髓阐微》
4. **不脑补**：原文没说的关系/结论，一律不加
5. **字符≠语义**：关键词出现不代表语义命中，必须看上下文
6. **宁漏勿错**：不确定的先放候选池，不硬切
7. **不混入现代文**：原文就是原文，白话译文不进canonical
8. **不混入评注**：徐乐吾评注、任铁樵注等后人内容，不进原文切片
9. **一个slice一个语义事实**：不要把多个独立论断合并到一个slice
10. **不自创category**：只能用G1-A已冻结的11个Domain及其Sub-domain
11. **准神归属必填**：每条切片必须标"准/旁参/被DTS否决"，拿不准进问题清单

## 八、v1.6关键理论口径（必须遵守，不得自行发挥）

以下是v1.6已经冻结的理论口径，子代理切片时必须对齐，不得按旧版或现代命理常识自行发挥：

### 旺衰判断
- ❌ 禁止："得令/失令是旺衰第一判据"
- ✅ 正确：得时（得令）/得地（通根）/得势（天干党众）三者合参，通根为主判据
- ❌ 禁止：只看月令
- ✅ 正确："只看月令是死法"——刘本原话精神

### 格局
- ❌ 禁止：子平专有的"月劫格"
- ✅ 正确：建禄/阳刃按人元司令取格归类
- ✅ 正确：格局主依据挂DTS定格法（月令透干/人元司令/杂气取土），PZZQ降旁参
- ❌ 禁止：现代从格五分法（从财/从杀/从儿/从势/从旺）
- ✅ 正确：从格=真从/假从；"五阳从气不从势、五阴从势无情义"
- ✅ 正确："从旺"归入专旺格（形象格），不列从格

### 调候
- ❌ 禁止："调候＞格局＞旺衰"归因DTS
- ✅ 正确：这是穷通宝鉴专有排序，DTS以中和为归
- ✅ 正确：调候出处回归DTS天干章（"甲木参天，脱胎要火"本是DTS原文）

### 赋论
- ✅ 正确：DTS自身韵文归DUANYU，准神归属=准
- ✅ 正确：他书赋文（太微赋/骨髓赋等）准神归属=旁参
- ✅ 正确：赋文是次级旁证，证据链最高层依据是DTS刘本原文

## 九、验收标准（主控会用这个标准验收你的切片）

| 检查项 | 合格标准 |
|---|---|
| 原文完整性 | 原文完整收录，不截断、不删节 |
| 原文真实性 | 确实来自该经典，不是后人编造 |
| 版本正确 | 对齐锁定底本，不混入其他版本内容 |
| ID唯一 | 有唯一ID，且格式正确 |
| 类型明确 | 规则型/原则型标注清楚 |
| **准神归属正确** | 标注为"准/旁参/被DTS否决"，且判定依据可追溯 |
| 适用范围明确 | 全局/日主/月令/格局，标注清楚 |
| Category正确 | 对齐G1-A ontology，不自创category |
| 无语义脑补 | 结论都是原文说的，不是推导的 |
| 无现代文混入 | 原文就是原文，白话译文不进canonical |
| 无水印噪音 | 没有页眉/页码/网站水印 |
| 章节定位 | 能精确定位到原著哪一章哪一段 |
| **依据链完整**（规则型） | 规则型切片有依据链，先挂DTS再挂余书 |

## 十、遇到存疑怎么办

1. 不要硬切
2. 把存疑的内容记录在 `_问题清单.md`（放在你工作的目录下）
3. 写明：哪本书、哪一段、为什么存疑
4. 准神归属拿不准的，也进问题清单，不要硬判
5. 主控统一汇总后处理
