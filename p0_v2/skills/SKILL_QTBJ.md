# Skill: 穷通宝鉴切片（QTBJ）

## 书籍信息
- 文件: D:\顺天系统资料\豆包资料\六部经典最终原著版\QTBJ_穷通宝鉴.txt
- 特点: 月令+季节+五行状态+调候+配合的调候专书

## 这本书的特点
最特殊的一本。不能按普通五行生克书切。
核心就是: 月令 × 日主 × 调候 × 配合

## 切片原则（铁律）
1. **按"月令专题"切**，不是按关键词扫
2. 每个切片是一个完整条件单元：
   - 对象: 某日主
   - 条件: 某月令
   - 气候: 寒暖燥湿
   - 需求: 某五行（主需求/次需求）
   - 配合: 某干/支
   - 结果: 某种成败
3. **旺衰 ≠ 调候**，调候单独切
4. **Relation只提取原文显式表达**

## QTBJ必切结构

### 按日主×月令切
十天干 × 十二月令 = 120个专题

每个专题切片：
```
甲木寅月 → 条件单元
甲木卯月 → 条件单元
甲木辰月 → 条件单元
...
乙木寅月 → 条件单元
...
```

每个条件单元提取：
1. 该日主在该月令的气候状态（寒暖燥湿）
2. 主需求（先取什么）
3. 次需求（次取什么）
4. 配合条件（某干/支）
5. 成败判断

### 调候专用分类
寒、暖、燥、湿、冻、炎、温、润、晦、清、浊
这些不能混进普通旺衰。

## 20类一级分类
重点用:
- YUE_LING（月令）
- TIAO_HOU（调候）
- WANG_SHUAI（旺衰）
- YONG_SHEN（用神候选）

## 验收标准
1. 10天干×12月令=120个专题全部切到
2. 每个专题有主需求+次需求
3. 调候字段独立，不混旺衰
4. 无理论推导
5. 无共现误判
