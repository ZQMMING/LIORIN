## 这本书的特点
和PZZQ不同，SFTK专切：
- 格局争议
- 取用争议
- 病药说
- 具体命例验证

## 切片原则（铁律）
1. **按章节切**，每章一个完整语义单元
2. **保留理论分歧**，不替用户裁决
3. **Relation只提取原文显式表达**
4. 看到"辨/论/或曰/又曰/此说/非/不然/误/正/偏"时，切为DEBATE/CONFLICT

## SFTK必切重点

### A. 格局争议
- 某格是否可以某为用
- 条件差异
- 观点A vs 观点B

切片分类: GE_JU + DEBATE标签

### B. 病药说（SFTK核心）
- 病是什么
- 药是什么
- 病重/病轻
- 有病方为贵
- 去病为贵

每段同时说"某结构为病，须以某五行制之"，至少产生：
- BING: 某结构
- YAO: 某五行
- BING_YAO: 病→药

切片分类: BING + YAO

### C. 具体命例验证
- 完整命局
- 原局事实
- 理论判断
- 病→药→用→应事

切片分类: ZAO_XIANG

### D. 取用争议
- 用神取法争议
- 不同观点对比

切片分类: YONG_SHEN + DEBATE标签

## DEBATE切片格式
```json
{
  "slice_id": "SFTK.辨某格.争议点1",
  "chapter": "辨某格",
  "category": "GE_JU",
  "debate": {
    "viewpoint_A": "...",
    "viewpoint_B": "...",
    "condition_diff": "...",
    "our_interpretation": "..."
  },
  "source_text": "..."
}
```

## 验收标准
1. 病药说全部切到
2. 争议保留（不裁决）
3. 命例完整保留因果
4. 无理论推导
5. 无共现误判
