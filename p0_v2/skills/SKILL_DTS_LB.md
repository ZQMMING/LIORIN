## 切片原则（铁律）
1. **按章节切**，每章一个完整语义单元，不按关键词扫
2. **Relation只提取原文显式表达**，不做理论推导
   - ✅ 提取: "木生火"、"甲己合"、"子午冲"
   - ❌ 不提取: 文中出现"木"和"火"就自动判"木生火"
3. **每个切片必须回答**: 这段原文在讲什么对象、什么关系、什么条件、什么结果
4. **不跨章节偷换主体**

## Relation提取规则（严格执行）

### 只提取以下显式表达
```
1. 五行生克（原文明确说"X生Y"、"X克Y"）
   ✅ "木生火" → SHENG(木,火)
   ✅ "金克木" → KE(金,木)
   ❌ 文中出现"木"和"火"但没说生克 → 不提取

2. 天干合（原文明确说"X+Y合"）
   ✅ "丁壬合" → TG_HE(丁,壬)
   ❌ 文中出现"丁"和"壬"但没说合 → 不提取

3. 地支冲（原文明确说"X-Y冲"）
   ✅ "子午冲" → CHONG(子,午)
   ❌ 文中出现"子"和"午"但没说冲 → 不提取

4. 其他干支关系（原文明确说）
   ✅ "寅亥合木" → DZ_HE(寅,亥)
   ✅ "亥卯未木局" → SANHE(亥,卯,未)
```

### 禁止提取
```
❌ 理论推导: 文中出现"木"就自动推"木生火"
❌ 共现误判: 文中同时出现"木"和"火"就判生克
❌ 同五行误判: "木--SHENG-->木"
❌ 方向反判: "水--KE-->金"（应该是金生水）
```
