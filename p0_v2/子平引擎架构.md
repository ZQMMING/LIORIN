### 1.2 四种计算范式

| 范式 | 用什么 | 禁止什么 |
|---|---|---|
| **布尔枚举**（条件触发） | True / False | 0.0~1.0 的连续置信度 |

**★ 四范式在底层的落定状态（2026-10-05，v2 补完成类型列）**

### 1.3 禁止浮点（四条理由）

1. **可复现性** —— 浮点有精度误差，同一输入在不同环境可能微差
2. **可审计** —— 每条结论能追溯到「哪条切片触发、哪条规则优先」；浮点权重求和算不清是谁贡献的
3. **准神规则要求** —— 准神裁决是**优先级**（primary/support/vetoed），不是加权
4. **五域并行要求** —— 域内主次是序数等级（0~4），域间并行是「全保留」，不是加权合并

| 裁决 | 符合 |
|---|---|
| 五域并行**不裁决** | ✅ 并列输出 |
| 域内主次**序数等级** | ✅ 0~4 |
| 准神裁决**优先级** | ✅ primary/support/vetoed |

### 1.5 三处直接影响

| 项 | 要求 |
|---|---|
| 严重程度评级 | 0/1/2/3/4 **序数** |

### 2.7 P1 病药层（五域并行）

**五域并行——不是候选，是并行的五个维度**：

| 病域 | 判据来源 | 病的内容 | 药的内容 | 主责经典 |
|---|---|---|---|---|
| **旺衰病域** | 身强身弱 | 财多身弱、杀重身轻、印重身轻、食伤泄秀过度、比劫夺财 | 扶抑药 | DTS（准）/SFTK |
| **结构病域** | 十神组合 | 官杀混杂、伤官见官、枭神夺食、财星破印、比劫争财 | 制化药 | SFTK/PZZQ |
| **气候病域** | 寒暖燥湿 | 寒、暖、燥、湿偏枯 | 调候药 | QTBJ（旁参·最系统）/DTS（准） |
| **格局病域** | 格局成败 | 破格、成中有败、败中有成、格局不清 | 救应药 | PZZQ（旁参·体系最密）/DTS（准） |
| **五行病域** | 五行偏枯 | 一行独旺、一行全无、两行相战、源流不畅 | 通关药/流通药 | DTS（准） |

**三条铁律**：

1. **病分五域，跨域不冲突** —— 五类病是五个独立维度，各自判定，并行输出
2. **药随病域，各出各的药** —— 每个病域有自己的药域，不互相替代
3. **同域分主次，跨域全保留** —— 同一域内多个病按轻重分主次，不同域的病全部保留

**输出契约**：
```
bing_list: [{bing_id, name, desc, classic, evidence, matched_facts, bing_wx, 病域, ...}]
```
- `bing_wx` = **病方五行**（水泛木浮=水、财多身弱=土）
- 依据链必须指到切片 ID

### 2.8 P2 冲突消解层

**目标：域内主次裁决 + 域间并行汇总。**

#### 2.8.1 域内主次裁决

| 依据 | 出处 | 说明 |
|---|---|---|
| 最多最旺者为源头 | DTS 源流章（准） | 同域内最旺者为主 |
| 病重药轻/病轻药重 | DTS（准） | 严重程度对比 |
| 药之有无 | DTS（准） | 局中有药 vs 无药 |

**输出**：该域内主病、次病、兼病。

#### 2.8.2 域间并行汇总

**不做跨域二选一，做跨域并行汇总。**

**输出**：

```
完整病机 = {
  '旺衰病域': {主病, 次病, 严重程度},
  '结构病域': {主病, 次病, 严重程度},
  '气候病域': {主病, 严重程度},
  '格局病域': {主病, 严重程度},
  '五行病域': {主病, 严重程度},
}

完整药方 = {
  '扶抑药': [主药, 辅药],
  '制化药': [主药, 辅药],
  '调候药': [主药],
  '救应药': [主药],
  '通关药': [主药],
}
```

**冲突消解层不做的事**：
- 不选「唯一主病」
- 不做「格局病 vs 气候病谁优先」的排序
- 不做「PZZQ 说无病 vs DTS 说有病谁对」的二选一

#### 2.8.3 严重程度评级（序数等级）

| 等级 | 含义 |
|---|---|
| 0 无病 | 该域无病 |
| 1 轻 | 有病但轻，不影响大局 |
| 2 中 | 有病，影响格局层次 |
| 3 重 | 有病，格局受损 |
| 4 极重 | 有病，命局偏枯 |

### 2.9 P2 用神层

**目标：基于五域药方取用神。多味并列，不选唯一。**

| 用神类型 | 来源病域 | 优先级 |
|---|---|---|
| 扶抑用神 | 旺衰病域 | 按严重程度 |
| 制化用神 | 结构病域 | 按严重程度 |
| 调候用神 | 气候病域 | 按严重程度 |
| 救应用神 | 格局病域 | 按严重程度 |
| 通关用神 | 五行病域 | 按严重程度 |

**多味用神并列时**：
- 某域严重程度明显高于其他域 → 该域用神为主用神
- 两域严重程度相当 → 两味并列为主用神
- 多域严重程度相当 → 多味并列，标「用神多元」

**关键：不再问「哪个用神是唯一正确的」，问「每域的用神是什么，各自严重程度如何」。**

## 四、改造项独立立项原则

**影响面不同、判定环节不同的改造项，必须独立立项，各自跑基线对比。**

| 项 | 判定环节 | 归因要点 |
|---|---|---|
| 从格改造项 A | **是否破格**（减法，只减少假破格） | 看破格判定变化 |
| 从格改造项 C | **破格后喜神如何记录**（记「存疑」，不清零） | 看「不一致（相反）」类是否归零 |
| 从格改造项 D（专旺/从旺入口） | **是否进入专旺/从旺判定**（入口） | 独立立项 |

**约束**：
- 改造项 C **不得先于** A 落地
- 保守边界：改造项只影响其**判定环节**
- 每项独立跑基线对比

**破格后喜神口径**：
```python
{
  'ge': '从财格(破格)',
  '破格标记': True,
  '格局域喜神': '存疑',        # 不清零, 不记"喜神"
  '格局域依据': 'CONG_GE_001', # 「既从矣，当论所从之神」——破格后如何定, 原典未言
  '其他域药方': '保留',         # 跨域不冲突
}
```

**理由**：① 病域并行——破格是格局域的病，不应清空其他域的药；② `CONG_GE_001` 未言破格后喜神如何 → 按铁律 3「宁漏勿错」记存疑；③ 记"喜神" = 脑补。

### 7.2 口径声明：破格清空 `ti_wx`/`xi_wx` 是否影响 P1

**声明结论：应影响。P1 读到空值是设计预期，不是缺陷。**

**依据链（三层）**：

| 层 | 依据 | 说明 |
|---|---|---|
| 1 | 代码内既有口径 | `bingyao_layer.py:570` 注释原文：「破格时格局层同时清空 `ti_wx`/`xi_wx`(同失效); 过旺例外(combo>=6)保留, 独立生效」 |
| 2 | 判据语义 | 破格 = 格已不成。原「成格路径喜神」已不成立，此时仍用它否决病机，等于**用一个已失效的格去否决别的域的病** —— §2.7 铁律 1 禁止的跨域否决的隐蔽形式 |
| 3 | 与 Step 1 的关系 | Step 1 解「**有效**格越权否决」；本条解「**失效**格越权否决」。方向相反，不构成回退 |

**反方主张**：「P1 应读破格前快照，避免格局域状态外溢。」

**不采纳**：破格后不存在有效的格局域喜神，读快照等于让格局域永远有否决权。与 §2.7 直接冲突。

**边界**：清空后两道过滤走假分支 → 整段不执行，语义是「不否决」；过旺例外（combo>=6）独立生效；破格后格局域自身如何重定 —— `apply_he_po_ge` docstring 明写「不重新定格，属格局回溯链」，留待专项。

### GAP-5 因果链：有切片不读，比无切片更严重（连接缺失子类）

```
P1 bing_domain = None            ← 引擎层(实测 1412/1412)
  ↑ 上游: 切片【已有】病域归属
PATHOLOGY.QI_HOU.008 frontmatter:
  > **病域归属**(v1.7 §0.3): 气候病域(QIHOU) —— 病=寒暖燥湿; 药=调候药 TIAO_HOU
  ↑ 引擎未读

→ 下游后果: P2 bing_debate 比较键 = (月令序数, 成党级别, -透干数, -本气根数)
   【四项中无「病域」】—— 不是「有域为空」，是根本没这一维
```
