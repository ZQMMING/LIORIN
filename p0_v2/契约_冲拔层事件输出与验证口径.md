# 契约：冲拔层事件输出与验证口径

钉死时间：2026-10-06　适用：得地层·冲拔算子（`engines/common/special_pattern.py` struck 块）

## 一、冲拔层定位（四条边界）

1. 冲拔层**只输出结构事件** `struck_root_events`，不输出日主旺衰、不判吉凶；
2. `clash_subject_tier`（含其六维 3360 格矩阵）是**内部临时量**，仅在裁决"冲胜负"时使用——不进 paipan 顶层、不作病触发/格局/吉凶输入、**不与 label 对比**；
3. "日支近身加成"无原文（原文只有"两支紧贴／冲月令为重"），QT-0121 类盘**不在冲拔层处理**；
4. 身无根、异党成势之盘（504 盘）是**从格/专旺成立结构**，"衰"≠"凶"，其与 label 的不一致不是冲拔反例。

## 二、struck_root_events 的 schema（每盘输出事件列表，事件独立不聚合）

| 字段 | 值域 | 说明 |
|---|---|---|
| `root_branch` | 子…亥 | 被冲的支（结构层只出支名，角色映射在验证层） |
| `clash_branch` | 子…亥 | 与根支构成六冲之支 |
| `route` | `KE` / `MIX` / `KU` | 冲对类型（**KU 独立路径，不走 KE 胜负**） |
| `distance` | `紧贴` / `坐支` / `隔一` / `遥隔` | 位置；`坐支`＝被冲根在日支（紧贴特例，优先标） |
| `uprooted` | 布尔 | 根是否被拔（与 library_opened **不互斥**） |
| `library_opened` | 布尔 | 是否开库（KU 路实际 true、uprooted false） |
| `resolved_by` | `无` / `六合` / `三合` / `三会` | 解冲来源（巳申刑合归六合，无"刑解冲"明文） |
| `basis` | 见下值域 | 该事件依据分级 |

`basis` 值域（写死，非自由文本）：
`DTS_CITED` / `BOOK_CITED` / `AXIOM` / `ENGINE_DEFINED` /
`ENGINE_DEFINED_PENDING` / `CASE_ONLY` / `INFERRED`

**跨层纪律**：schema 只放结构层可判事实；`target_role`（用神根/印根）与"去病取清/破格"结论**不进事件层**——由上层或验证脚本读 `root_branch` 后做"支→十神角色"映射。

## 三、冲对四路裁决（执行顺序写死）

- **KU 库冲**：判定条件＝**两支都在 {辰戌丑未} 且构成「辰戌」或「丑未」两对组合**（同属土）。丑未藏干虽互克，不影响开库判定。KU **不走拔根**，`library_opened=true`、两根存活（DTS L96「库宜开」/ 五行精纪四库冲）；
- **KE 纯相克（子午、卯酉）**：`clash_pair_state`＝两支五行各自月令位（ling_state），旺方根存活、只拔衰方（DTS L108/L110）；
- **MIX 混合（寅申、巳亥）——执行序写死**：
  1. **先**判相生神门控；门控**通过 → 直接不拔**，不再走 KE；
  2. 门控**不通过 → 回落 KE**，按 L108 pair_state 定旺衰胜负；
  3. 相生神门控（ENGINE_DEFINED）：本气根／月令相旺有中余根／透干有中余根为有力，仅虚透无根不算（五行精纪「冲处要相生」）；
- **距离生效**：仅**紧贴**可产生拔根/开库生效；**隔一、遥隔的冲仍进事件列表**，但 `uprooted=false`、`library_opened=false`（事件存在、力弱不生效），以便下游区分"没冲"与"冲了没拔"；
- **解冲承接**：L0 resolved 已判 canceled 的冲，事件 `resolved_by` 标对应合/会（六合/三合/三会），`uprooted=false`；巳申刑合归六合。

依据分级：近重远轻定性有 PZZQ L852「贴近为克，遥动为冲」、L842「相去一间」、L2269「隔位性质大变」；**离散三档切分＝ENGINE_DEFINED**。

## 五、验证口径（不比 label，比事件命中断语）

1. 从案例断语抽取**事件描述**，做事件级语义蕴含映射：
   - 「冲去禄神，其根已拔」→ `{root=寅/禄, uprooted=true}`
   - 「冲开辰库」「库逢冲而发」→ `{library_opened=true}`
   - 「寅申冲，暗生不拔」→ `{route=MIX, uprooted=false}`
2. 与 DTS 语义蕴含回放同款，出**事件命中率**＝断语事件与引擎事件一致率；
3. 事件正确＝冲拔层正确；事件→吉凶是格局/病药/调候/岁运层的事；
4. **禁止**用 good/bad label 验证冲拔层（504 盘已证伪）。
