### 1.2 合化成立条件——组合展开（八判据，核六合章全文穷举）

**原文判据（PZZQ 化气篇/六合案例 + DTS + SMTH/YHZP 六合章）：**

```
判据甲 天干之助（PZZQ 明文）:
  "地支之三会六合，亦须天干之助，方能会合而化也"
  → 化神透干: 子丑化土须戊己透 / 寅亥化木须甲乙透
    卯戌化火须丙丁透 / 辰酉化金须庚辛透 / 巳申化水须壬癸透 / 午未化土须戊己透
  ★ 案例: 子丑化土真 = 干透戊己（PZZQ 稼穑）; 子丑不化 = 干透壬癸（PZZQ 煞旺身衰）
判据乙 化神当令（直接用 L3 ling_state ∈ {旺, 相}——已建成, 非 PENDING）:
  "支临寅亥，必然化木"——支成木局; "辰酉合而化金"在金旺/申酉
  ★ 当令定义 = ling_state[化神] ∈ {旺, 相}（月令×五行→旺相休囚死, L3 已有）
判据丙 化神不足 / 闲神伤化 = 假化（PZZQ 明文）:
  "日主无根，而化神不足者；更有合化虽真，而闲神来伤化气者，皆为假化"
判据丁 合而不化——原五行作用保留（DTS/PZZQ）:
  DTS"子丑之合，不化亦是克水，喜水者必不吉也"
  PZZQ"乙庚合而煞仍留"（合而不化，煞仍在局）
判据戊 争合 / 妒合（PZZQ 明文）:
  PZZQ"然则如何方为争合妒合乎？此须察其地位也"
    —— 两壬夹丁（壬辰丁未壬寅）= 争合妒合; 三丙争合一辛"又不能化，多夫之象"
  DTS"虽合不化，有争合、妒合、分合之别"
  YHZP"一位夫星，有两位妻星相合，谓之争合，若本身自旺，彼身值衰，四柱不冲，则我正而彼为偏"
  → 争合=两干争合一干（夹/多对一）; 胜负判据 YHZP: 自旺彼衰+不冲 → 我正彼偏; 彼旺我衰 → 偏
判据己 紧贴 / 隔位（PZZQ 明文）:
  "此须察其地位也"——合须察位置; 三合"亥未隔申，不能成局"（隔位不成局, 六合类推）
  → 紧贴方为合; 隔位不合作合论（或降为弱合）
判据庚 合忌刑破 / 空破休囚（SMTH/YHZP 六合章明文）:
  YHZP"六合，忌刑破，况柱中见合力露"
  SMTH"六合，忌休囚、空破"
  → 合处逢刑/冲/破/空 = 合不成或力减
判据辛 解冲/引冲胜负 = 合方与冲方旺衰较量（PZZQ 案例）:
  "寅亥之合，似可解寅申之冲，无如申金秉令，亥中壬甲休囚"——冲方秉令则合不胜冲
  "一卯不冲二酉，乃以辰酉之合，引起卯酉之冲"——合力引出冲
  → 解冲须合方旺于冲方; 冲方秉令则引冲/解不成
```

### 1.6 六合 vs 天干五合接口（合去维度前置）

```
① 天干五合（甲己/乙庚/丙辛/丁壬/戊癸）: 合的是【透干】——判透干十神被合
   地支六合: 合的是【支】——判支藏干十神被合 / 支的根被合
② 同时存在: 互不干涉——各判各的; 合去维度按被合对象分层读:
   透干用神被合走 → 天干五合判定
   支根/支藏用神被合走 → 地支六合判定
   支中暗干被露干合（暗合）→ DTS"若露干合支中暗干，则随局无所不合"（判据己扩展）
③ 优先级: 天干五合管透干层, 六合管地支层, 暗合管跨层——不设总优先级, 按对象路由
   （PZZQ 高太尉"两乙合庚，甲日隔之，仍作合煞留官"——天干合不受地支局影响, 印证分层）
④ 合走忌神=解（官杀取清）, 合走用神=破（用神被合去）——方向判定在各层合判定完成后
```
