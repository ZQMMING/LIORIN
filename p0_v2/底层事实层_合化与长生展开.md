### 1.2 合化成立条件——组合展开

**原文判据（PZZQ 化气篇 + DTS 案例）：**

```
判据甲 天干之助（PZZQ 明文）:
  "地支之三会六合，亦须天干之助，方能会合而化也"
  → 化神透干: 子丑化土须戊己透 / 寅亥化木须甲乙透
    卯戌化火须丙丁透 / 辰酉化金须庚辛透 / 巳申化水须壬癸透 / 午未化土须戊己透
  ★ 案例: 子丑化土真 = 干透戊己（PZZQ 稼穑）; 子丑不化 = 干透壬癸（PZZQ 煞旺身衰）
判据乙 化神当令或成局（DTS/PZZQ 案例）:
  "支临寅亥，必然化木"——支成木局（寅亥+卯/辰）
  "寅亥化木"多例在木旺/春令; "辰酉合而化金"在金旺/申酉
  → 月令或支局助化神方真
判据丙 化神不足 / 闲神伤化 = 假化（PZZQ 明文）:
  "日主无根，而化神不足者；更有合化虽真，而闲神来伤化气者，皆为假化"
  ★ 假化不是"不化"——是有化象但力不足，作用弱化
判据丁 合而不化——原五行作用保留（DTS/PZZQ）:
  DTS"子丑之合，不化亦是克水，喜水者必不吉也"（合而不化，子水仍克火）
  PZZQ"乙庚合而煞仍留"（合而不化，煞仍在局）
```

**组合矩阵（判据甲 × 判据乙 → 化/假化/不化）：**

| 化神透干(甲) | 化神当令/成局(乙) | 结果 | 案例 |
|---|---|---|---|
| 透 | 当令/成局 | **化真** | 子丑透戊己+稼穑；丁壬透+支临寅亥；辰酉化金 |
| 透 | 失令无局 | 假化（力不足） | PZZQ"合化虽真，而闲神来伤化气者，皆为假化"；DTS 卯戌假化有情 |
| 不透 | 当令/成局 | 合而不化（原性保留） | PZZQ 壬子癸丑丙午壬辰（透壬癸非戊己→不化土，煞旺身衰）；DTS 子丑不化亦克水 |
| 不透 | 失令无局 | 合而不化（最弱） | 一般合，仅解冲/引冲（见 1.4） |

### 1.3 六合解冲 / 引冲功能（PZZQ 大量案例——六合不只化，还承担冲刑调停）

```
解冲: 卯戌合解卯酉冲（PZZQ 陆荣廷造"因卯戌之合，而解卯酉之冲也"）
      卯戌合解子卯刑（PZZQ 杜锡珪造"因卯戌之合，而解子卯之刑也"）
      午未合解丑未冲（PZZQ 齐耀琳造"午未合本可解丑未之冲"）
引冲: 辰酉合引起卯酉冲（PZZQ 赵观涛造"一卯不冲二酉，乃以辰酉之合，引起卯酉之冲"）
      辰酉合复引起巳亥冲（PZZQ 赵铁桥造）
      子午冲复引起丑未冲（PZZQ 齐耀琳造——因子午之冲复引起丑未之冲）
刑带合: 巳申刑而带合（PZZQ"巳申刑而带合，去申中庚金"）
暗合:   卯酉冲因申中庚与卯中乙暗合而解（PZZQ 孔祥熙造）
★ 六合对冲刑的功能 = 解 / 引 / 带刑——三态, 每对 × 每刑冲对 组合待全表（本轮列案例所见, 缺格标 ENGINE_DEFINED）
```
