## 六、立规清单（工作规范，已进 `shuntian-slice-audit` 技能）

```
1. 独立进程验证，禁持久 kernel

   COMPUTED / META_FIELD / PENDING；未声明类型的字段不得进契约

2c. 元规（上位规）：分类/统计优先用【结构标识】
   —— ID 前缀 / 字段类型 / 枚举值 / AST 节点类型；
      文本模式（关键词/正则）只作辅助，不作最终判据

2d. 「全 0」是一等信号，先怀疑扫描器
   —— 凡「全部 0 / 全部相同」，先跑探针验证扫描器本身

2e. 脚本写完必先过【已知答案的样例】，再跑真实数据

   探针不 PASS → 该脚本的任何数不许进下一轮
   未报探针的结果 = 默认不可信，撤回重跑
```
