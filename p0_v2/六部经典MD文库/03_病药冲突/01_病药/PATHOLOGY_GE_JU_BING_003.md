## 原文

伤官见官果难辨，可见不可见。

**原注**：身弱而伤官旺者，见印而可见官；身旺而伤官旺者，见财而不见官。伤官旺，财神轻，有比劫而可见官；日主旺，伤官轻，无印绶而可见官。伤官旺而无财，一遇官而有祸；伤官旺而身弱，一见官而有祸；伤官弱而财轻，一见官而有祸；伤官弱而见印，一见官而有祸。大率伤官有财，皆可见官，伤官无财，皆不可见官。又要看身强身弱，何财官、印绶、比肩不同方可，不必分金、木、火、土也。又曰伤官用印，无财不宜见财；伤官用财，无印不宜见印，须详辨之。

---

## 语义解析

**对象**：伤官格的格局病——伤官见官。
**关系**：伤官有无财、身旺身弱、见印见财，决定见官是祸是不祸；有财可见官，无财不可见官。
**条件**：以伤官旺弱、财之轻重、身之强弱、印之有无为辨。
**结果**：无财而见官、身弱伤旺而见官等，皆见官有祸，为伤官格之真病。

### 一、核心判定矩阵（伤官见官可见/不可见）

依据原注逐句拆解，引擎须构建以下条件分支：

**可见官（不构成格局病）的成格条件：**

1. **身弱 + 伤官旺 + 有印** → 见官可见。
   - 依据：原注「身弱而伤官旺者，见印而可见官」。
   - 取用：以印制伤护官，印为用神。

2. **身旺 + 伤官旺 + 有财** → 见官可见。
   - 依据：原注「身旺而伤官旺者，见财而不见官」及「大率伤官有财，皆可见官」。
   - 取用：以财化伤生官，财为用神。

3. **伤官旺 + 财轻 + 有比劫** → 见官可见。
   - 依据：原注「伤官旺，财神轻，有比劫而可见官」。
   - 取用：比劫助身任官，财虽轻而身有根，伤官有泄路。

4. **日主旺 + 伤官轻 + 无印** → 见官可见。
   - 依据：原注「日主旺，伤官轻，无印绶而可见官」。
   - 取用：身旺能任官，伤轻不至克官太甚，无印则不夺食伤之秀。

**不可见官（一见官即有祸，构成格局病）的破格条件：**

5. **伤官旺 + 无财** → 见官有祸。依据：原注「伤官旺而无财，一遇官而有祸」及「伤官无财，皆不可见官」。
6. **伤官旺 + 身弱** → 见官有祸。依据：原注「伤官旺而身弱，一见官而有祸」。
7. **伤官弱 + 财轻** → 见官有祸。依据：原注「伤官弱而财轻，一见官而有祸」。
8. **伤官弱 + 见印** → 见官有祸。依据：原注「伤官弱而见印，一见官而有祸」。

### 二、用神互斥规则（印财不相见）

依据原注末句「伤官用印，无财不宜见财；伤官用财，无印不宜见印」，引擎须设互斥校验：

- **伤官用印格**：原局无财，大运流年见财 → 财破印，用神被损，判为引祸。
- **伤官用财格**：原局无印，大运流年见印 → 印夺食伤、阻财源，判为引祸。

此条与上述矩阵叠加：若伤官用财格本无印而见印，即使原局有财可见官，亦因印来破用而转为病局。
