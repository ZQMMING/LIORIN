## 一、定位

本文件定义 `病域归属` / `药域归属` 两个字段的**取值集合**。
它是**字段值定义**，不是 Domain 定义。G1-A Ontology 的 11 个顶层 Domain 不变。

## 四、`CROSS_CUTTING` 三条约束

### 约束 1：不是域

`CROSS_CUTTING` **不新增** `PATHOLOGY` / `MEDICINE` 下的 sub-domain。
G1-A Ontology 的 11 个顶层 Domain 不变，既有 ID 段不新增。

### 约束 2：规则层必须指定作用域

**引用 `CROSS_CUTTING` 切片的规则，必须显式声明本条作用于哪一域（或哪几个域）。**

```
✅ 规则引用格式：
   规则 R-0XX："…"（依据 PATHOLOGY.ZHI_FA.021 · CROSS_CUTTING）
        作用域 = 全部五域（总纲约束，不产出具体喜神取值）
```

```
❌ 错误：直接用 ZHI_FA.021 判定某格喜神，不声明作用域
```

**理由**：无作用域声明的总纲切片会被任意规则引用，等于绕开 v1.7 §0.4「跨域不冲突」。

### 约束 3：不直接触发匹配

`CROSS_CUTTING` 切片**不参与 `ge_jie_layer` 分支匹配**，只作：
- 依据链（`依据1/依据2` 字段）
- 总纲约束（须配合作用域声明）
- 人工复核参照

**与 `DUANYU` 赋论层同级处理**。

**理由**：总纲讲"怎么治"的通则，若允许直接触发匹配，
`ZHI_FA.005`（中和）会变成"任何格都按中和判"，覆盖五域各自判据。

---

## 五、与 `DUANYU` 的层级关系

| 项 | `CROSS_CUTTING` | `DUANYU` 赋论层 |
|---|---|---|
| 是否 Domain | **否**（字段取值） | 是（11 Domain 之一） |
| 是否触发匹配 | 否 | 否 |
| 作用域声明 | **必须** | 不必须 |
| 准神地位 | **保留原典地位**（DTS 来源可 primary） | 次级旁证（v1.6 §7.13） |

**关键差别**：`CROSS_CUTTING` 不是"降级的赋论"，是**跨域的准神依据**。
