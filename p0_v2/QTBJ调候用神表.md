## 一、120 格 schema（定稿 v2，带正/变格）

每项调候为结构化对象 `{yao, is_variant, src_line}`：

| 字段 | 含义 |
|---|---|
| gan | 日干（甲乙…） |
| yue | 月令（寅卯…丑） |
| main | 主调候 `{yao,is_variant,src_line}` |
| aux | **有序**辅调候列表 `[{yao,is_variant,src_line},…]`，按原文"次/又次"出现序 |
| src_text | 提纯后原文句 |
| is_pure | 是否纯原文（true＝已剔后人注） |
| basis | BOOK_CITED / ENGINE_DEFINED |

- **正/变格**：is_variant=false 为正格、true 为变格（如未月 癸正/庚丁变）；
- **aux 有序**：QTBJ 歌诀体，"次/又次"即重轻序（壬水正月"庚源、次丙、又次戊"为证），P2 取药按序。

## 二、提纯规则（可执行，从甲木样板固化）

1. 节标题后紧跟 `原 文` 标记；**标记后、重复节名之后的第一段＝主调候原文**（main/aux 取此）；
2. **行首 `徐乐吾曰：`＝后人注，剔除**（CASE_ONLY 旁参）；
3. `或 / 如 / 凡 / 总之` 开头的无标记段＝**原文变格/配合**，保留作门控佐证（如"水泛木浮""财多身弱"）；
4. 四柱实例段＝案例。
判据：行首标记（主）＋段落位置（主），文风（辅）。
