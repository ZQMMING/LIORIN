> 依据分级：判定原则 DTS《滴天髓》刘基原注 §29寒暖/§30燥湿（DTS_CITED）；
> 调候取药 QTBJ《穷通宝鉴》原文（BOOK_CITED）；过偏量化 ENGINE_DEFINED。
> **QTBJ md 混入"徐乐吾曰"及现代白话，非纯原著；本表逐节从"原 文"段取证，剔后人注，不凭记忆。**

## 一、120 格 schema（定稿 v2，带正/变格）

每项调候为结构化对象 `{yao, is_variant, src_line}`：

| 字段 | 含义 |
|---|---|
| gan | 日干（甲乙…） |
| yue | 月令（寅卯…丑） |
| main | 主调候 `{yao,is_variant,src_line}` |
| aux | **有序**辅调候列表 `[{yao,is_variant,src_line},…]`，按原文"次/又次"出现序 |
| src_text | 提纯后原文句 |
| is_pure | 是否纯原文（true＝已剔后人注） |
| basis | BOOK_CITED / ENGINE_DEFINED |

- **正/变格**：is_variant=false 为正格、true 为变格（如未月 癸正/庚丁变）；
- **aux 有序**：QTBJ 歌诀体，"次/又次"即重轻序（壬水正月"庚源、次丙、又次戊"为证），P2 取药按序。

### 版式抽查（2026-10-06，丙火/壬水/戊土）
丙火正月 L2383"取壬为尊，庚金为佐"；壬水正月 L7483"宜庚金之源，次丙火，又次戊土"。
**提纯内容规则通吃**（节首"原 文"段取主调候、徐乐吾曰剔除）。
**但节切分各干不统一**：戊土为合并节"正二月戊土"（L4207），非每月独立；
合并段内还须分句归月（L4210"正二月先透丙、三月先透甲"同月不同用）。
故 108 格不可只按"正月X…十二月X"固定标题盲批量；须先枚举每干实际节标题（正二月/五六月等合并），
逐节抽段、合并节分句归月。丁火/己土部分月同此。
取证底稿：`p0_v2/qtbj_120_main_segments.txt`（已抽 94 节，待补合并节）。

## 二、提纯规则（可执行，从甲木样板固化）

1. 节标题后紧跟 `原 文` 标记；**标记后、重复节名之后的第一段＝主调候原文**（main/aux 取此）；
2. **行首 `徐乐吾曰：`＝后人注，剔除**（CASE_ONLY 旁参）；
3. `或 / 如 / 凡 / 总之` 开头的无标记段＝**原文变格/配合**，保留作门控佐证（如"水泛木浮""财多身弱"）；
4. 四柱实例段＝案例。
判据：行首标记（主）＋段落位置（主），文风（辅）。
