> 状态：**写死，不可绕过**（2026-10-06 拍板）
> 适用：顺天子平引擎一切案例验证、切片验证、回归测试、调试。
> 违反本条 = 跑空、白跑，结果一律不认。

---

## 一、唯一权威源

**四柱输入 → 排盘引擎 `l0_chart` 是唯一权威源。**

子平引擎主链**不得重复自算**任何关系/查表，只消费排盘引擎输出。

```
四柱(八字)
   │
   ▼
临时排盘接口  engines.l0_paipan._chart_from_pillars
   │  产出 l0_chart（全套事实）
   ▼
子平引擎 l0_fact_builder / relations_builder / 各层消费
   │
   ▼
格局成败 + 病药（原局）
```

调试入口：`p0_v2/bazi_gate.py::paipan(bazi)`（八字四柱字符串，可带空格）。

---

## 二、必须走排盘接口的事项（强制）

| 事项 | 必须 |
|---|---|
| **跑案例**（六书 `case_audit/*_clean.jsonl`） | 四柱先过排盘接口，再进子平引擎 |
| **案例验证 / 回归** | 同上；不接排盘的跑数结果**不认** |
| **切片验证**（先用 md 文件做验证） | 切片条件所依赖的事实（藏干/十神/冲合/空亡等）必须取自排盘输出 |
| **新规则落码 / 改判据** | 先确认输入事实来自排盘，再谈判据 |
| **真实盘调试** | 一律四柱输入走 `paipan()`，禁止手填事实 |

**一句话：不接排盘接口，不许跑案例、不许验切片。**

## 五、禁止事项

1. **禁止**绕过排盘接口直接给子平引擎喂手填/自算事实。
2. **禁止**在主链重新引入本地关系表做判定（兜底除外）。
3. **禁止**不接排盘就跑案例、跑回归、验切片——结果作废。
4. **禁止**两边重复计算同一关系（排盘算一遍、子平再算一遍）。
5. 异常**不得静默吞掉**：排盘/子平出错要暴露，禁止用"无病"掩盖崩溃。

---

## 六、验证口径（每次改动后必跑）

1. 真实盘四柱走 `paipan()`，核对藏干 / 十神 / 空亡 / 冲合输出。
2. 全量 good/bad 回归：当前基线 **62.2%**（good 777/1121、bad 131/338）。
3. **0 崩溃、0 异常**。
4. 95 测试全过（逐脚本 `python tests/test_*.py`；pytest 收集器对脚本式测试 INTERNALERROR，忽略）。

> 吉凶不在原局判——原局只做**格局成败 + 病药**；吉凶到喜神 / 忌神 / 大运阶段才判。
> 规则原著优先：以刘基原注 / PZZQ 原著为核心，任铁樵注仅旁参。
