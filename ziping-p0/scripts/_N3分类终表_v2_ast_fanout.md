## 分桶方法(纯 ast, 无正则碰词)
```
引擎每 .py 用 ast.parse 出节点类型, 每行承载分 6 类:
  BRANCH      If/While/Match 判据分支(条件里含判据词)     → 强
  JUDGE_TABLE 表变量 被 If 比较消费 (ast 收 Name)          → 强
  TABLE_CONST 普通常量/枚举表(非判据入口)                   → 弱
  APPEND      文案/结果输出                                 → 弱
  DOC         docstring                                     → 弱
  META        溯源表(值含 condition_id/evidence_refs)        → 弱
另: tokenize 出 非承载行(注释/文案) 词 → 撤出碰词证据
输出/回显层(meta_unified_output/dayun_summary/liunian_summary/execution_demo) 整文件剔

三轮:
  R1 关键字"含if/return" → 46%(作废)
  R2 ast 结构类型        → 229 = 真25 + 弱127 + 撤76 + 未1
  R3 fanout(N条判据句共撞同一引擎行→catchall) → 真必切25 再拆 独享8 + catchall17
```
