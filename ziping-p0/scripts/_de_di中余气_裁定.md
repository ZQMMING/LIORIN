## 一、准神原典依据（PZZQ L201，沈孝瞻原文层）

```
L201 引句:「是故十干不论月令休囚，只要四柱有根，便能受财官食神而当伤官七煞。
          长生禄旺，根之重者也；墓库余气，根之轻者也。
          得一比肩，不如得支中一墓库…得二比肩，不如得一余气…盖比劫如朋友之相扶，通根如室家之可住；干多不如根重，理固然也。」

→ 原典「根」= 长生禄旺(重) + 墓库余气(轻)，**中余气明言算根**，只分级重/轻，不算"无根"。
→ L204 补:「见夏水冬火，不问有无通根，便为之弱…不以为…通根身库，甚至求刑冲开之。此种谬论，必宜一切扫除」
   = 沈孝瞻明确批「不通根(中余气)就判弱」是谬论。

★ 准神口径: 有根 = 有 本气/长生禄旺/墓库余气 任一(分级), 非只本气。
```
