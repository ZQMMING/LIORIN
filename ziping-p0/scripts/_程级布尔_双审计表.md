## 三、PZZQ 成破（纠3：L261/L516 不是"成>破"）

```
★ 撤 "PZZQ L261/L516 给成>破明文" —— 字面误推

L261 原文:「成中有败, 必是带忌; 败中有成, 全凭救应」
   = 【双向互含】: 成格必带忌, 败格必靠救应 —— 成/败都需看(忌/救应), 非"成优先"

L516 原文:「格局既成, 即使满盘孤辰入煞, 何损其贵? 格局既破, 即使满盘天德贵人, 何以为功?」

   = 这是"成 vs 破"的【分叉判据】, 不是"成 > 破"的【排序】

正解: 成破 = 双向互含(带忌/救应) + 层位(格局>星曜), 无"成优先于破"的程级明文
      → L4 成破冲突消解 = ENGINE_DEFINED(带忌则成转败, 救应则败转成, 无绝对优先)
```
