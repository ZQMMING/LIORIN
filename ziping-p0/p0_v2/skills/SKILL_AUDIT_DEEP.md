# 深查Skill：逐本核查遗漏+错误

## 任务
对六本书切片v2做深度核查，找出：
1. **遗漏**：原文有但没切的章节/语义单元
2. **错误**：切错的、方向反的、多切的
3. **格式问题**：字段缺失、格式不对

## 核查方法

### 第一步：覆盖率核查
- 对照原文目录/章节结构
- 列出所有应该切的章节
- 对比实际切了多少
- 找出遗漏的章节

### 第二步：Relation核查
- 逐条检查每一条Relation
- 方向对不对？（SHENG/KE方向）
- 有没有共现误判？（只是同时出现，原文没说关系）
- 有没有理论补全？（按五行生克理论推的，不是原文说的）

### 第三步：source_text核查
- source_text是不是原文？（不能改写）
- 有没有截断/拼接错误？

### 第四步：字段完整性
- slice_id/book/section/chapter/category/subject/source_text/source_location/conditions/result/relations/status 12个字段全不全？

## 输出格式

```
## {书名} 深查报告

### 覆盖率
- 原文章节数: X
- 已切章节数: Y
- 遗漏章节:
  1. 章节名 - 原因（该切没切）
  2. ...

### Relation错误
- 总Relation数: X
- 错误: Y
  1. slice_id: xxx
     Relation: 甲--SHENG-->火
     原文: "..."
     错误: 方向反/共现/理论补全

### 格式问题
1. slice_id: xxx
   缺字段: conditions
```

## 原则
- 宁可漏掉，不能多切
- 但该切没切的必须找出来
- 错误的必须修
- 用原著原文验证，不靠理论
