# L3 从格族规格草案

## F0 总闸：日主无根无气

### 定义
```
F0 = 无根 ∧ 无气 ∧ 根气未被救
```

### 【无根】
地支不含日主之本气/中气/余气根：
- 甲乙：寅卯（本气）、辰未（余气）
- 丙丁：巳午（本气）、戌丑（余气）
- 戊己：辰戌丑未（本气）
- 庚辛：申酉（本气）、戌丑（余气）
- 壬癸：亥子（本气）、辰（余气）

**争议点**：墓库余气（如未中乙、戌中丁）是否计入根？
→ 待裁决（需古籍断语支撑）

### 【无气】
天干无比肩劫财、无正印偏印；或比印全被合去/克尽。

### 【根气未尽破】
以下任一情形视为"根犹存"，不从：
- (a) 根支未被冲（寅申、卯酉、巳亥、子午、辰戌、丑未）
- (b) 根支未被合化变性（寅亥合木、辰酉合金等）
- (c) 印星未被财星紧贴克破

**争议点**：根被冲是否算破根？
→ 《滴天髓》任注与《真诠》有分歧，待裁决

## F1-F4 四从

| 从格 | 条件 |
|---|---|
| F1 从财 | 财星独盛，日主弃命从财 |

## 假从四种类型（闭合集合）
全部为减项→MID，非硬闸：

| 类型 | 可执行判据 | 古文对应 |
|---|---|---|
| F-假从·有根 | 日主存一余气根或墓库根，未被冲克尽 | 「从之不尽」「根气未除」 |
| F-假从·有印 | 天干透印，但印星无根或被财克 | 「印有根则不从」「印被财破，勉强可从」 |
| F-假从·有比劫 | 天干见比劫帮身，但比劫被合去/被官杀制 | 「比劫夺财而不真」 |
| F-假从·旺神不纯 | 所从之神被它神干扰而力不纯 | 「不作真从而论」 |

**旺神不纯细分：**
- 从杀见食伤制杀（如J1：酉金食神+卯酉冲杀）
- 从财见比劫争财
- 从儿见印星克食伤
