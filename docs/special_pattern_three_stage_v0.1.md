## 段一：优先级（严格 if → elif → else，无默认分支）

裁决顺序：

```
1. 化气格      （天干五合 + 月令引化 + 无争合克破）
2. 两神成象    （两行平分，各占约半）
3. 专旺格      （一行独旺）
4. 从格        （弃命从势/从财/从杀/从儿/从官）
5. 正格        （else）
```

**关键纪律：**
- 每一层必须是「通过才返回，不通过就 fall through」
- 绝不能有 `else: return 专旺格` 这种兜底
- 化气格交叉表中 26.8% 被专旺抢走，根源就是这两层平行排列、专旺检查先命中

**互斥切分（第2/3层）：**
- 最旺五行占比 ≥ 70% → 专旺
- 两行合计 ≥ 80% 且单行 < 60% → 两神成象
- 阈值写死在 docstring 里，不许在调参时改

## 段二：门槛段（五格各自硬门槛，全部满足才成立）

| 格局 | 月令当旺 | 地支条件 | 天干条件 |
|------|---------|---------|---------|
| 曲直格 | 寅卯月（春木） | 亥卯未三合 / 寅卯辰三会 / 卯木多现 | 甲乙透干或比劫 ≥2 |
| 炎上格 | 巳午月（夏火） | 寅午戌三合 / 巳午未三会 | 丙丁透干 |
| 稼穑格 | 辰戌丑未月（四季土） | 土支 ≥3 且无木局 | 戊己透干 |
| 从革格 | 申酉月（秋金） | 巳酉丑三合 / 申酉戌三会 | 庚辛透干 |
| 润下格 | 亥子月（冬水） | 申子辰三合 / 亥子丑三会 | 壬癸透干 |
| 化气格 | 月令引化所化之五行 | 不依赖地支合局 | 日干与邻干五合 + 化神透干 + 无争合 |

**注意润下格的边界：**
- L902「六水乘权」、L656「四柱皆水」都在这类
- 如果实现只数「水支 ≥3」，会把「天干一片火土而地支三水」的正格收进来
- **月令当旺必须是门槛而非加分项**

## 段三：破格字段（一票否决）

### A类：见即破格，降为正格

- 曲直格见庚辛申酉（官杀）
- 炎上格见壬癸亥子
- 稼穑格见甲乙寅卯
- 从革格见丙丁巳午
- 润下格见戊己辰戌丑未（官杀）／土重混局

### B类：转格，不归正格

- 见财星成势 → 转从财
- 食伤过重泄身 → 转从儿
- 官杀成势无制 → 转从杀

### C类：失令即降（专门吃 L190、L726）

- 「丁火生季冬」「春金失令」这类表述 = 月令不当旺
- 直接 fall through 到正格，不进任何专旺分支

**反证组4条100%假阳性，根源就在C类和A类缺失：**
- L2035「坐下申金」= 炎上格见财官破格（A类）
- L726「春金失令」= 失令（C类）
- L471「丁火独透」= 独透不成势
- L1811「天地交战」= 破格（A类）

## 重构纪律（这次不能破）

1. **基线已冻结**（05ab0f20），输出物只有三个数：翻转率、翻转案例命中率变化、全量delta。其他一律不看。
2. **按格分步提交**：先改专旺（最大杠杆），跑一次数；再改化气，再跑一次。不要五格一起改，否则错了无从定位。
3. **门控不动**。等专旺干净后，enable_tiaohou 自然跟着干净。
