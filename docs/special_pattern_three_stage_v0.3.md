## 段一：优先级（严格 if → elif → else，无默认分支）

裁决顺序：

```
1. 化气格      （天干五合 + 月令引化 + 无争合克破）
2. 两神成象    （两行平分，各占约半）
3. 专旺格      （一行独旺）
4. 从格        （弃命从势/从财/从杀/从儿/从官）
5. 正格        （else）
```

**关键纪律：**
- 每一层必须是「通过才返回，不通过就 fall through」
- 绝不能有 `else: return 专旺格` 这种兜底
- **else分支守卫：遍历509条，任何一条判定路径必须命中某个if条件全满足: return X，不允许落到最终else。命中else直接抛异常而不是返回正格。**

**互斥切分（第2/3层）：**
- 最旺五行占比 ≥ 70% → 专旺
- 两行合计 ≥ 80% 且单行 < 60% → 两神成象
- 阈值写死在 docstring 里，不许在调参时改

### B类复合条件（v0.3新增，吃"独透"案例）

**财星成势（满足任一）：**
- 财星地支≥2
- 财星得令透干
- **财星为全局唯一异党且无制**（v0.3新增，吃L2035"坐下申金"）

**食伤过重（满足任一）：**
- 食伤天干≥2
- 食伤得令且透干
- **食伤为全局唯一异党且无制**（v0.3新增，吃L471"丁火独透"）

**异党定义：** 非本行且非食伤的五行。异党天干数量≤1 且地支无本行根气 → 视为不成势，降为正格。

- 吃L190"丁火生季冬"、L726"春金失令"

**第三件：else分支守卫**

- 不允许落到最终else

## 重构纪律（这次不能破）

1. **基线已冻结**（05ab0f20），输出物只有三个数：翻转率、翻转案例命中率变化、全量delta。其他一律不看。
2. **按格分步提交**：先改专旺（最大杠杆），跑一次数；再改化气，再跑一次。不要五格一起改，否则错了无从定位。
3. **门控不动**。等专旺干净后，enable_tiaohou 自然跟着干净。
4. **验收闸门**：新规则必须13真例全过、7假例全拦。达不到就回规格修v0.4，不许动用例。
