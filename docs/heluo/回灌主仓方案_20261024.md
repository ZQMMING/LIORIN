## 四、推荐路径（**渐进、可回滚**）

**阶段 0（本轮可做，零行为变更）**
- 主仓加**可选依赖探测**：`try: import heluo_engine except ImportError: None`；
- 装了就用新能力，没装**行为与现在完全一致**（不崩、不降级日志噪声）；
- 加守卫：未装包时主仓主链路输出**逐字不变**。

**阶段 1：河洛计算切到独立包（Q1=a / Q2=b）**
- `compute_stage._compute_heluo_yi` 改走 `heluo_engine.adapter.HeluoAdapter`；
- 副本保留为转发层（薄壳），旧 import 路径不断；
- **回归重点**：出生时间口径（真太阳时/日界）、流年干支（公历年 vs 立春年）、
  流日目标日（`target_date` 缺省 = 今天）—— 这三处是主仓与新包**行为不同**的点。

**阶段 2：河洛信号进 canonical 通道（Q3）**
- `build_canonical_signals` 追加 `heluo_engine.canonical_signals.build_platform_signals(result)`；
- 河洛信号带 `source_engine="Heluo"`、`temporal_scope`（YEARLY/MONTHLY/DAILY）与**正确的目标日**
  （2026-10-24 修复后 DAILY 信号落在目标日，而非日段首日）。

**阶段 3：规则库与事件候选**
- 河洛侧已产出 `event_candidates`（17 类**候选** + 有据方向 + 能力缺口清单）；
- 平台侧按《河洛机制到平台事件类型落位提案_20261024.md》的 5 问裁定后，
  再把候选转成正式事件类型。

## 五、回归清单（回灌时逐项验）

1. 主仓既有全量测试**零回归**（基线数字须先记录）；
2. **出生时间口径**：真太阳时 / 23:00 日界 / 儒略历（1582 前）三处对拍；
3. **流年干支**：公历年 vs 立春年的边界（1/1–2/3 的年份）；
4. **流日目标日**：缺省 = 今天（北京时间）；显式 `target_date` 时**流日落在该日**；
5. **canonical 通道**：河洛信号的 `temporal_scope` 与 `start_day/end_day`；
6. **死断展示管控**：死断原句**不得**进 summary（河洛侧已钉死，主仓消费时须沿用）；
7. `api` 输出体积与前端契约。
