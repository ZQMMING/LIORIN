## 六、审计结论与处理建议

### 6.1 总体结论

1. **87%的补丁有原著依据**（DIRECT 60.9% + COMMENTARY 26.1%），引擎核心规则忠实原著。
2. **13%为纯工程推导**（3个），均为架构决策或防御性逻辑，无案例拟合。
3. **无需要回退的活跃补丁**。所有ENGINEERING级补丁去掉后对齐率下降均>0.5pp，应保留并标记PROVISIONAL。
4. **V5.4冬夏/非冬夏仲裁**是COMMENTARY级中最需要关注的补丁——依据梁湘润注释而非原文，建议在代码中明确标注`COMMENTARY_DERIVED`。

### 6.2 处理建议

| 等级 | 处理 | 具体动作 |
|------|------|----------|
| DIRECT | 保留 | 作为核心规则，无需额外标注 |
| COMMENTARY | 保留+标注来源 | 在代码注释中增加`# COMMENTARY_DERIVED: 来源（如梁湘润注）` |
| ENGINEERING | 保留+标记PROVISIONAL | 在代码注释中增加`# ENGINEERING_PROVISIONAL: 工程推导，无原著依据` |

### 6.3 后续工作

1. **V5.4标注COMMENTARY_DERIVED** — 冬夏/非冬夏仲裁依据梁湘润注释，需明确标注
2. **V6.3/V7.5-V7.8/V7.18标注ENGINEERING_PROVISIONAL** — 3个工程推导补丁
3. **过拟合源已基本清除** — 37个PCT-MARK常量已0处消费，wuxing_power.py的ratio已降级为LEGACY_REFERENCE
4. **独立验证集验证** — 非DTS可判率仅10.8%是硬约束，盲测结果（75%）与DTS（79.1%）方向一致，无过拟合信号
