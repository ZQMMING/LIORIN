# 子平八字引擎前端展示规范 v1.0

> 版本：v1.0 | 日期：2026-09-21 | 基线：79.0%单一对齐率 + 98.2%命中率@K

## 一、设计原则

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| 诚实呈现 | 不隐藏不确定性，冲突保留多解明确标注 |
| 分层展示 | 主结论优先，辅助信息折叠，用户按需展开 |
| 来源可追溯 | 每个判断标注来源轨道（格局/调候/病药/体用） |
| 可解释性 | 每个结论附带推理依据，不是黑盒输出 |

### 1.2 输出类型分类

引擎输出分为4种类型，每种类型有不同的展示方式：

| 输出类型 | 触发条件 | 展示方式 |
|----------|----------|----------|
| 单一结论 | 元素级与互动级一致 | 直接展示，标注置信度 |
| 冲突保留（多解） | 元素级与互动级冲突 | 并列展示+来源标注+冲突说明 |
| 分看输出 | 大运前5/后5判断不同 | 前5/后5分别展示，整体结论标注 |
| 互动检测 | 有实质性互动关系 | 作为提示标注，不改变主结论 |

## 二、单一结论展示

### 2.1 展示结构

```
┌─────────────────────────────────────┐
│ 大运：甲寅                            │
│ 主判断：喜 ✅                         │
│ 依据：甲木印比帮身（扶抑轨）          │
│ 置信度：高（元素级与互动级一致）       │
└─────────────────────────────────────┘
```

### 2.2 字段说明

| 字段 | 来源 | 展示方式 |
|------|------|----------|
| 大运干支 | dayun.ganzhi | 标题 |
| 主判断 | element_judgment.result | 喜/忌/中性，带颜色标识 |
| 依据 | element_judgment.reason | 一句话说明 |
| 来源轨道 | yongshen_paths | 标签（格局/调候/病药/体用） |
| 置信度 | conflict.has_conflict | 高（无冲突）/中（有互动但无冲突） |

### 2.3 颜色规范

| 判断 | 颜色 | 图标 |
|------|------|------|
| 喜 | 绿色（#22c55e） | ✅ |
| 忌 | 红色（#ef4444） | ❌ |
| 中性 | 灰色（#9ca3af） | ⚪ |

## 三、冲突保留（多解）展示

### 3.1 展示结构

```
┌─────────────────────────────────────┐
│ 大运：癸亥                            │
│ ⚠️ 冲突保留：元素级与互动级判断冲突    │
├─────────────────────────────────────┤
│ 【元素级判断】                         │
│ 喜 ✅  癸水帮身（扶抑轨）             │
├─────────────────────────────────────┤
│ 【互动级判断】                         │
│ 可能忌 ⚠️  合化木，作用改变           │
│ 互动类型：六合+三合                    │
├─────────────────────────────────────┤
│ 【综合说明】                           │
│ 取决于合化是否成功，建议结合流年细断    │
│ 来源：冲突保留架构（V7.18）           │
└─────────────────────────────────────┘
```

### 3.2 字段说明

| 字段 | 来源 | 展示方式 |
|------|------|----------|
| 冲突标识 | conflict.has_conflict | ⚠️ 警告图标+标题 |
| 冲突类型 | conflict.type | 副标题（元素级喜 vs 互动级可能忌） |
| 元素级判断 | element_judgment | 独立卡片，标注来源 |
| 互动级判断 | interaction_judgment | 独立卡片，标注互动类型 |
| 综合说明 | conflict.resolution | 底部说明，不强行裁决 |

### 3.3 交互设计

- 默认展开元素级判断，互动级判断折叠
- 用户点击"查看互动级影响"展开互动级卡片
- 冲突说明始终可见，提醒用户存在不确定性
- 提供"我该信哪个？"按钮，展开来源轨道优先级说明

### 3.4 来源轨道优先级说明

当用户点击"我该信哪个？"时，展示：

| 条件 | 优先级 | 依据 |
|------|--------|------|
| 生于亥子丑或巳午未月 | 调候轨优先 | 《穷通宝鉴》"调候为急" |
| 生于其他月份 | 格局轨优先 | 《子平真诠》"专求月令" |
| 格局破 | 病药轨优先 | 《神峰通考》"有病方为贵" |
| 从格/专旺格 | 体用轨优先 | 《滴天髓》"从象" |

## 四、分看输出展示

### 4.1 展示结构

```
┌─────────────────────────────────────┐
│ 大运：庚午（10年）                     │
│ 整体判断：喜（被削弱）                 │
├──────────────┬──────────────────────┤
│ 【前5年】      │ 【后5年】            │
│ 天干：庚（金）  │ 地支：午（火）       │
│ 判断：喜 ✅     │ 判断：中性 ⚪        │
│ 依据：庚金印比  │ 依据：午火官杀       │
│ 帮身           │ 被天干庚金削弱       │
└──────────────┴──────────────────────┘
│ 分看模式：渊海子平（前5天干/后5地支）  │
│ 来源：V7.20分看判断逻辑                │
└─────────────────────────────────────┘
```

### 4.2 字段说明

| 字段 | 来源 | 展示方式 |
|------|------|----------|
| 整体判断 | overall.result | 顶部展示，标注"被削弱/被缓解" |
| 前5年判断 | first_5.result | 左卡片，天干主导 |
| 后5年判断 | last_5.result | 右卡片，地支独立 |
| 天干/地支 | first_5.gan / last_5.zhi | 卡片标题，带五行 |
| 分看模式 | overall.mode | 底部标注（渊海/三命/滴天髓） |

### 4.3 多模式切换

引擎支持3种分看模式，前端可提供切换：

| 模式 | 依据 | 逻辑 |
|------|------|------|
| 渊海子平 | 《渊海子平》 | 前5年天干，后5年地支 |
| 三命通会 | 《三命通会》 | 前5年干+支，后5年弃干 |
| 滴天髓 | 《滴天髓》 | 十年整体，盖头截脚修正 |

默认使用渊海模式，用户可切换查看不同经典的分看方式。

### 4.4 交互设计

- 前5/后5卡片并排展示，当前年份高亮
- 鼠标悬停显示详细依据（天干喜忌+地支喜忌）
- 提供"为什么前5和后5不同？"按钮，展开分看逻辑说明
- 整体判断标注"被削弱/被缓解/加重"，说明前后5年的差异影响

## 五、互动检测展示

### 5.1 展示结构

```
┌─────────────────────────────────────┐
│ 大运：甲寅                            │
│ 主判断：喜 ✅                         │
├─────────────────────────────────────┤
│ 💡 互动检测提示（不改变主判断）        │
│ 互动类型：六冲                         │
│ 互动关系：CHONG_DAY_PRIMARY           │
│ 冲支结果：衰者拔                       │
│ 说明：大运寅木冲原局申金（用神根）    │
│ 可能影响：用神根被拔，喜神可能失效     │
│ 建议：结合流年细断，注意申金被冲的年份 │
└─────────────────────────────────────┘
```

### 5.2 字段说明

| 字段 | 来源 | 展示方式 |
|------|------|----------|
| 互动标识 | interaction_judgment.has_interaction | 💡 提示图标 |
| 互动类型 | interaction_judgment.types | 标签（六冲/六合/三刑/三合等） |
| 互动关系 | interaction_judgment.relations | 技术标签（可折叠） |
| 冲支结果 | transit_clash_verdicts | 衰者拔/旺者发/两停 |
| 说明 | 自动生成 | 一句话说明互动对象和后果 |
| 建议 | 自动生成 | 提醒用户注意的年份和方向 |

### 5.3 互动类型图标

| 互动类型 | 图标 | 颜色 |
|----------|------|------|
| 六冲 | ⚡ | 橙色 |
| 六合 | 🔗 | 蓝色 |
| 三刑 | ⚠️ | 红色 |
| 六害 | 🕳️ | 紫色 |
| 六破 | 💔 | 粉色 |
| 三合 | 🔺 | 绿色 |
| 三会 | 🔷 | 青色 |
| 天干五合 | 🤝 | 黄色 |

### 5.4 交互设计

- 互动检测默认折叠为一行提示，不展开详细内容
- 用户点击"查看互动详情"展开完整信息
- 互动关系（relations）默认隐藏，技术用户可展开查看
- 明确标注"不改变主判断"，避免用户混淆
- 提供"这个互动意味着什么？"按钮，展开通俗解释

```
  ●----●----●----●----●----●----●----●

```

### 6.2 字段说明

| 字段 | 来源 | 展示方式 |
|------|------|----------|
| 大运干支 | dayun.ganzhi | 时间轴节点 |
| 大运年份 | dayun.years | 时间轴刻度 |

- 冲突保留的大运节点标注⚠️，提醒用户存在不确定性

## 八、响应式设计

### 8.1 桌面端（>1024px）

- 大运时间轴横向展示
- 冲突保留双栏并列（元素级左/互动级右）
- 分看输出双栏并列（前5左/后5右）
- 互动检测侧边栏

### 8.2 平板端（768-1024px）

- 大运时间轴横向可滚动
- 冲突保留双栏并列
- 分看输出双栏并列
- 互动检测折叠

### 8.3 移动端（<768px）

- 大运时间轴纵向展示
- 冲突保留单栏堆叠（元素级上/互动级下）
- 分看输出单栏堆叠（前5上/后5下）
- 互动检测折叠为图标

## 九、无障碍设计

### 9.1 颜色对比度

- 喜/忌/中性颜色满足WCAG AA级对比度
- 不只用颜色区分，同时使用图标（✅/❌/⚪）

### 9.2 屏幕阅读器

- 所有判断结果有aria-label
- 冲突保留有role="alert"
- 互动检测有aria-expanded状态

### 9.3 键盘导航

- 大运时间轴可通过左右箭头切换
- 所有可展开区域可通过Enter/Space触发
- Tab顺序符合视觉顺序

## 十、性能优化

### 10.1 懒加载

- 大运详情卡片懒加载，只渲染当前可见大运
- 互动检测详情按需加载

### 10.2 缓存

- 命局分析结果缓存（相同八字不重复计算）
- 大运喜忌结果缓存

### 10.3 骨架屏

- 计算过程中显示骨架屏，避免空白
- 骨架屏结构与最终输出一致
