## 一、公理（AGENTS.md 第一条）

### 公理一：六部经典在断言层自洽

凡出现「两格互抢」「定义冲突」，一律先视为**工程建模错误**，而非古籍冲突。

### 公理二：引擎不得拥有任何原著没有的字段

「身弱」不在原著判定路径上（原著有的是得令/失令、有根/无根），故**不许出现在定格入口**。

### 公理三：每一条规则必须能指到一句 grade=A 的原话

指不到，就是你在替古人说话。指得到但版本存疑，必须标注 `source_version`。

> 公理三将"幻觉"由道德问题转化为结构问题：编不出出处，就过不了闸门。

## 二、六经职能归一表（纯传统本）

| 经典 | 核心职责 | 管辖层 | 明确不管什么（防抢案闸门） | 关键原句 |
|------|---------|--------|--------------------------|---------|
| 《渊海子平》 | 定名权 + 月令正格 + 外格名录 | 格局命名层 | 不管旺衰权衡、不管调候细节 | 《玄机赋》《碧渊赋》专旺五格；《论运化气》干合配支局 |

| 《滴天髓》（传统本） | 气势极端情形：专旺、从象、化象、两气成象 | 气势层（正格的补充） | 不另立一套命名体系 | 「两气合而成象，象不可破也」；「从得真者只论从」；「化得真者只论化」 |
| 《穷通宝鉴》 | 气候：十干逐月调候用神 | 调候层（正交维度） | 不参与定格，只打标 | 「正月甲木…得丙癸透」；「正二月甲木，素无取从财、从杀、从化之理」 |
| 《三命通会》 | 旺衰分量表：旺相休囚死、寄生十二宫 | 原子分量层 | 自己声明不作吉凶结论 | 「见生旺者未必便作吉论…妙在识其通变」 |

> 右数第二列是关键。每本书的"不管什么"构成天然防抢案闸门——只要引擎遵守这些边界声明，就不会出现"化气格与专旺格互抢"，因为《渊海》从未把化气设为独立格局。

## 四、格局定义改写为合取式（决胜内嵌，不设外部优先级）

### 【从革格】（专旺·金） ← 原「化金气格」并入此格

```
= zhiju_full(巳酉丑 ∨ 申酉戌)
∧ tougan(庚辛)
∧ ¬(官杀透干 ∧ 无制)          ← 《渊海》要义：见庚辛官杀即非此格
∧ ¬kepo(金)
```

**出处：**
- 《渊海·碧渊赋》「庚辛局全巳酉丑，位重权高」
- 《渊海·论运化气》「乙庚化金…巳酉丑全，曰从革」← 干合侧要件
- 《滴天髓》方局／独象

★ 「天干化合者秀气，地支合局者福德」之一格，故化气不另立桶

### 【弃命从财】

```
= dangzhong_net(比劫印) ≈ 0
∧ root_benqi(日主) == 0
∧ 财星成势透干
∧ ¬(印星透而生身)            ← 《真诠》「若透印则身赖印生而不从」
∧ deling ≠ 禄旺              ← 《穷通》排斥条款
```

**出处：**
- 《子平真诠》弃命从财条
- 《滴天髓》「从得真者只论从」

### 【两神成象】

```
= 全局本气仅两行 ∧ 力量相当 ∧ ¬第三行透干破局
```

**出处：**
- 《滴天髓·形象》「两气合而成象，象不可破也」
- 【原注】「若见金水则破，余仿此」

> 关键机制：决胜条件作为合取的一项写进定义内部，外部不再设「谁打败谁」的优先级链。「从得真者只论从」本身就是从格的定义项，无需另写裁决器。外部优先级链之所以显得必要，往往是因为内部定义不够完整。

## 九、Phase 顺序

- **Phase 0**（本文件）：锁 AGENTS.md v3 —— 公理 + 六经职能表 + 判定元清单 + A/B/C 闸门
- **Phase 1**（Qwen 3.8，只读）：按 schema v3 重切 513 条，逐条标 source_grade / source_version
- **Phase 2**（人工，验收）：抽检 20 quote + 四桶和 + grade=C 清零入规格
- **Phase 3**（重跑 baseline）：用新切片重跑 baseline，拿第一份干净数字
- **Phase 4**（格局重构）：
  - 4.1 删化气格桶并入专旺五格（一次归位 li=66 + 6 条 FN）
  - 4.2 补两神成象判定（只用 A 级三条）
  - 4.3 从格收紧（TP ≥ 19/32 才动）
  - 4.4 一次一格 + 偷窃量闸门
- **Phase 5**（格局层冻结 → 调候层）

> 心理准备：Phase 3 的一致率很可能先跌。分母变干净、旧标签作废、自创的格被删，都会拉低数字。跌掉的是虚高水分。真正该盯的是**未归因案例数**，它应当单调递减至 0；若一致率涨而未归因数不动，说明系统在自我迎合。
