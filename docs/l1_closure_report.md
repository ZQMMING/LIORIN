## 五、三句关键注记

### 1. A3修正：闭环自证的教训
原期望MID系按「戌土为财」设定，实际减项只认天干透财，地支藏财不计。  
**教训：** 只要期望值挂在旧引擎上，旧引擎的错误就会传染给用例，再用例反过来「证明」旧引擎正确。oracle切换不是优化，是拆掉这个闭环。

### 2. H2穷尽性：一条覆盖五格
专旺格日主必属该行，故「本行不透」等价于「天干除日主外无同类」。  
**结论：** H2一条用例即覆盖五格，非遗漏四条。

### 3. 边界声明
22条中15条为专旺格fixture，L1仅覆盖专旺族与化气型一条。  
**注意：** 这是规则维度的高覆盖，不是格局空间的高覆盖，不得作为全系统验收依据。
