## 三、规格变更清单

### ① 当令判定（G2）三层口径

```
本气月：月令 ∈ 化神三合局
  木=亥卯未 / 火=寅午戌 / 土=辰戌丑未 / 金=巳酉丑 / 水=申子辰
次旺月：木=寅 / 火=巳 / 土=午 / 金=申 / 水=亥
季月引化：月令 ∈ 辰戌丑未 ∧ 化神支局全 → 当令，但降一档取 MID
```

### ② 季月引化的择一理由

《子平真诠》会合化表谓十二月丙辛不化，唯三月（辰）因「辰为水库故化」。本引擎取《滴天髓》原注「甲日主生于四季……而有一辰字，乃为化得真」，以「支局全」为季月引化之必要条件。

此与《真诠》相左，择《滴天髓》者，以其与《神峰通考》方状元造相合，且「借局代令」之理与 47 章「四支局全则成格」之梯度同源。此路仅于「局全」强条件下生效，且一律降 MID，不过生成。

### ③ provenance 新增 A-

**A-**：原文断语明确且可考，但与本引擎所择体系存在公开冲突，或断语仅断格局种类未断档次。期望值按引擎体系定，出处仍保留以供复核。

## 六、边界声明（最重要）

1. **验证的是规格，不是古人。** 41 条绿条中，38 条的期望值由本引擎规格推出，只有 3 条来自古籍断语。因此绿条证明的是「实现符合规格」，不能直接等同于「符合子平」。
2. **锚点存在正面冲突。** R8 张楠将其列于「化之真者，名公巨卿」纲下，后世另有论者直指该造「水有根气，当以合不化论、财格生官论」，甚至质疑「宋无萧姓丞相」。此类命例只能作为参照，不能作为判决。
3. **体系归属已择一。** 主纲《子平真诠》，气势补《滴天髓》，调候与神煞不入格局闸。凡与此冲突者，均已登记择一理由，不再视为 bug。
4. **化气型边际收益已耗尽。** 八道闸全实现、五格对称验证、三条外部锚点、零白名单。继续堆细化用例对整体可信度提升微乎其微。
5. **格局层仅完成约 2/5。** 从格族、正格八格、建禄月劫阳刃、外格杂格、格局成败救应均未启动；大运流年层、断语输出层为零。化气型的骨架可复用，但工程量还在后面。

## 最后一句

L2 开始时，化气型只有 R7 一条锚点，八道闸里有七道是靠自己推出来的规格撑着的。

结束时，它留下了三件比「41/41」更实在的东西：

- **三个被外部命例抓出来的错**（b4 复用闸门、争合漏日干、G2 抄了专旺的口径）。如果没有那两条红条，这三个会一直活到封版，而且永远不会被发现——因为所有用例都是自己造的，它们恰好都通过了自己定的规则。
- **一次档位梯度的外部验证**。「次等之贵」「减分」「略嫌」，古人本来就有三档，只是没用 CONFIRMED/MID/REJECT 这几个词。三档不是拍脑袋。
- **一个可复用的分歧处理流程**：不许改期望值 → 登记 divergence → 核原文 → 区分「bug / 规格过严 / 体系冲突」→ 各自走各自的路。这套流程在 L3、L4 还会用几十次。
