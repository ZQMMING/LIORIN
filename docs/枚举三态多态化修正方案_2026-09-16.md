# 枚举三态/多态化修正方案（2026-09-16）

> 依据：V2.22 FINAL 附录 L（值域治理）+ 用户裁决「整个引擎必须三态或多态，禁布尔化」2026-09-16
> 铁律：每个枚举必须含 `UNKNOWN`（或 `UNDETERMINED`）兜底值；古典本当多态的不得压成二态；同一语义不重复注册；与附录 L 冲突的对齐附录 L；单值必须补反态。
> 说明：DTS 古籍语义层枚举（中文值）补 `UNDETERMINED`；架构层枚举（英文值）补 `UNKNOWN`。两者按 V2.22 既有惯例区分。

---

## 一、问题总览

| 类别 | 数量 | 风险 |
|---|---|---|
| 二态枚举（36 条，8 ACTIVE + 28 PENDING） | 36 | 缺中间态/兜底值，规则消费「值缺失」= 误判 |
| 单值枚举（9 条，全 PENDING） | 9 | 无反态，状态机无法表达「不满足」 |
| **合计问题枚举** | **45/74（61%）** | 枚举混乱 → 产出错误 |

另发现：
- `xing_state` 字段语义污染：「定」（寿段）与「形全/形缺」（形全形缺篇）两个不同语义共用一个字段
- `shangguan_ge_state`（清/浊）与 `qing_state` 重复注册（desc 自述「复用 qing_state」）
- `dts_day_master_strength`（衰/旺）与附录 L-3 `strength_state`（六级）冲突

---

## 二、修正原则（V2.22 附录 L 铁律）

1. **每个枚举必须含兜底值**：二态 → 三态（A/B/UNKNOWN）；三态+ → 保留多态 + UNKNOWN 兜底
2. **古典本当多态**：按原文值域展开（如清浊四态），不得压成二态
3. **同一语义不重复注册**：`shangguan_ge_state` 删除，复用 `qing_state`
4. **与附录 L 冲突对齐**：`dts_day_master_strength` 二态（衰/旺）→ 弃用，改用附录 L-3 `strength_state` 六级；如需保留古典层则改名 `day_strength_classic`（WANG/SHUAI/JUN_HENG）——已有
5. **单值补反态 + UNKNOWN**：如 `tian_status`: 全一氣/非全一氣/UNDETERMINED
6. **字段语义污染拆分**：`xing_state`（性定）→ 改名 `xing_ding_state`；形全形缺保留 `xing_state`（形全/形缺/UNDETERMINED）

## 四、消费层同步要求

1. **state.py**：所有输出字段必须恒有值（永不缺失）——二态必落反态，单态必落反态+UNDETERMINED
2. **rules.dts.jsonl**：删除引用 `shangguan_ge_state` 的规则条件 → 改用 `qing_state`；`xing_state=定` 消费改 `xing_ding_state=定`
3. **禁止**：规则消费「字段缺失」作为判定（必须显式消费 UNKNOWN/UNDETERMINED 或具体值）
