### 2.1 命宫地支

**公式** (来自《紫微斗数全书》):
```
命宫地支 = 寅起正月顺数到生月，该宫起子时逆数到生时
```

**代码实现**:
```python
def calc_soul_branch(month, shichen):
    return BRANCHES[(2 + month - 1 - shichen) % 12]
```

**测试结果** (8个案例交叉验证):
```

✅ 1974年三月申时 → 命宫地支=申
✅ 1984年闰十月申时 → 命宫地支=亥
✅ 2000年正月子时 → 命宫地支=午
✅ 1990年五月午时 → 命宫地支=寅
✅ 1985年八月辰时 → 命宫地支=辰
✅ 1976年十二月戌时 → 命宫地支=戌

### 2.3 命宫天干

**公式** (五虎遁):
```

**测试结果**: 8个案例全部通过 ✅

### 2.4 五行局
