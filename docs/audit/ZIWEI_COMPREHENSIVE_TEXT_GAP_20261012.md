## 三、接线缺陷（原诊断未发现，实为关键 bug）

`interpretation.py` 未提交改动（`_synthesize_dimension_conclusion`，L2121-2165）中新增的**自化解读段**存在死代码：

```python
# 自化需要从 chart 获取，这里通过 engine 调用
if self._engine and hasattr(self._engine, 'get_all_zihua'):
    try:
        chart_dict = {"palaces": {}}
        if hasattr(state, '_chart_ref'):      # ← 恒为 False
            chart_dict = state._chart_ref
        zihua_map = self._engine.get_all_zihua(chart_dict)   # ← 恒返回 {}
```

**证据链**：

1. `ZiweiDimensionState`（L1063）**无 `_chart_ref` 字段**，构造点（L1919、L1988）也未传入。
2. 全 `src/` 检索 `_chart_ref`，**仅此一处引用**（另有 `.pyc` 残留）。
3. `get_all_zihua(full_chart: dict)` 内部执行 `full_chart.get("palaces", {})` → 恒定入参 `{"palaces": {}}` → **恒定返回 `{}`**。
4. 因此 `if palace_name in zihua_map` 恒为 False，段落永不产出。

**排除误判**：`get_all_zihua` 的数据通路本身是通的——实测 `full_chart()` 返回的 `ZiweiChart` 对象可直接传入：

```
get_all_zihua type: dict
keys sample: ['迁移', '疾厄', '子女', '夫妻']
value sample: ['自化禄']
```

且 `domain_reading.build_domain_readings(chart, zihua_map)` 消费同一份数据可正常产出：

```
迁移 -> 迁移自化禄，外出机遇多
疾厄 -> 疾厄自化禄，体质底子好，但容易忽视保养
子女 -> 子女自化科，子女文雅好学
夫妻 -> 夫妻自化忌，感情上自我纠结，容易反复
```

**结论**：`ZIHUA_BY_PALACE` 文案表**完整存在**，`domain_reading` 通路**正常**；
唯一故障是 `interpretation._synthesize_dimension_conclusion` 里的 `chart_dict` 拼装取错对象，
导致自化解读**在综合断语里 100% 丢失**。

> 修法（不动对外契约）：该函数签名已有 `state`，而 `chart` 在 `ZiweiLifeReadingBuilder` 作用域内可达；
> 应把 `chart` 显式传参，或给 `ZiweiDimensionState` 增加 `chart_ref` 字段并在 L1919/L1988 构造时赋值。
> 推荐前者（传参），避免给纯数据类挂实体引用。

## 五、缺陷二：领域宫位静默丢失（本轮新发现）

`_build_domain_readings` 的宫位解析：

```python
related = [p for p in palace_names if p in pr_map]
```

`pr_map` 键取自**实际盘内宫名**。实测 iztro 产出为 **`仆役`**：

```
盘内十二宫名: ['夫妻','兄弟','命宫','父母','福德','田宅','官禄','仆役','迁移','疾厄','财帛','子女']
含'交友': False | 含'仆役': True
```

而 `DOMAIN_PALACES` 此前声明「交友」→ 两领域各丢一宫：

| 领域 | 声明宫位 | 实际解析 | 丢失 |
|------|---------|---------|------|
| 学业 | `['交友','命宫','官禄']` | `['命宫','官禄']` | **交友** |
| 人际 | `['兄弟','交友','命宫']` | `['兄弟','命宫']` | **交友** |

**根因**：`PALACE_DIM_MAP` 已做 `交友`/`仆役` 双键兼容，`DOMAIN_PALACES` 漏做。
`pr_map` 无该键即静默跳过，不报错、不留痕。

**修复**：
1. `DOMAIN_PALACES` 收敛为盘内实际宫名「仆役」
2. 新增 `PALACE_ALIAS` 别名表（`交友 → 仆役`）
3. `_build_domain_readings` 增加别名回退，声明名缺失时尝试别名
