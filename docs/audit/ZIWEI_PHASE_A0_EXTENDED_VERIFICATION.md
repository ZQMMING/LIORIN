## 一、真太阳时验证

### 1.1 函数接口

```python
def corrected_hour_index(self, hour, longitude, solar_date):
    """真太阳时校正后的时辰 index
    
    Args:
        hour: 北京时间小时 (0-23)
        longitude: 出生地东经 (度)
        solar_date: 阳历日期 (y,m,d)
    
    Returns:
        校正后的时辰 index
    """
```

### 1.2 测试结果

| 测试用例 | 输入 | 输出 | 预期 | 状态 |
|---------|------|------|------|------|
| 早子时(00:00) | hour=0 | index=0 | 0 | ✅ |
| 午时(11:00) | hour=11 | index=6 | 6 | ✅ |
| 晚子时(23:00) | hour=23 | index=12 | 12 | ✅ |
| 东经115°修正 | hour=11, lng=115 | index=5 | 5 | ✅ |
| 东经125°修正 | hour=11, lng=125 | index=6 | 6 | ✅ |
| 无经度修正 | hour=11, lng=None | index=6 | - | ✅ |

### 1.3 关键发现

**均时差(Equation of Time)影响**

当 `longitude=120°E`（北京标准经度）时，由于均时差的存在，`corrected_hour_index` 仍会产生微小修正：

```python
# 2000-01-01 均时差 ≈ -3.5分钟
# 所以 11:00 → 10:56:30 → index=5 (巳时)
engine.corrected_hour_index(11, 120, (2000, 1, 1))  # 返回 5 而非 6
```

**结论**: 真太阳时校正已完整实现，包含经度差修正和均时差计算。

| 星名合法 | 所有星名在已知星曜列表中 | ✅ |
| 与流年不同 | 流月四化 ≠ 流年四化 | ✅ |
| 多月份不同 | 不同月份四化不同 | ✅ |
| 连续验证 | 与流年/大限形成完整链条 | ✅ |

### 3.3 流月四化原理

流月四化由**月干**触发，不同于流年（年干）、大限（大限干）。

```python
# 验证: 2000年不同月份的流月四化不同
jan = engine.flow_month_mutagen(2000, 1, (2000, 1, 15), 12, 'male')
feb = engine.engine.flow_month_mutagen(2000, 2, (2000, 2, 15), 12, 'male')
assert jan != feb  # 月干不同，四化不同
```

### 4.3 流日四化原理

流日四化由**日干**触发，是四时间尺度中最细的一层：

```
本命盘 → 大限(十年) → 流年(一年) → 流月(一月) → 流日(一日)
   ↓         ↓           ↓          ↓          ↓
生年干   大限干      流年干     月干       日干
```
