## 二、任务A：B2「黄土主温/主湿」定案（重点挂起项）

### 结论

**温/湿之问定案为「温」。** 底本与全部通行本系统均作「溫」，**无任何版本作「濕」**——B2 原怀疑的「温 vs 湿」反义异文**不成立**。

底本实际与通行本的差异不在温/湿，而在**底本多一「黃」字**：

| | 文本 |
|---|---|
| 底本（国图崇祯本 YHZP-118-004） | **黃**土主**溫**，多淹滯，面色痿黃 |
| 维基文库 | 土主**温**，多淹滞，面色痿黄 |
| 中华典藏 diancang.xyz | 土主**温**，多淹滞，面色痿黄 |
| 豆丁网 docin.com | 土主**温**，多淹滞，面色痿黄 |
| 起点阅读 qidian.com | 土主**温**，多淹滞，面色痿黄 |
| 韩国낭월명리학당（繁体） | 土主**溫**，多淹滯，面色痿黃 |

- **性质**：字差（底本加「黃」字），非反义。
- **语义影响**：不影响疾病规则语义——「土主温，多淹滞」语义自洽；底本「黃土主温」仅多一修饰字。
- **记录**：已按 schema 追加至 YHZP-118-004 `text_variants`，loc=`黃土主溫句（B2）`，human_verdict=PENDING。
- **依据源**：维基文库 + 中华典藏 + 豆丁 + 起点 + 낭월（五源一致作「土主温」，无「黄」字、无「湿」字）。

## 三、任务B：「火主燥皮肤枯燥」句核查（C 类存疑）

### 结论：两短语均真实存在，但分属不同段，非同一句

| 短语 | 底本是否存在 | source_id / 篇名 | 底本原文（繁体逐字） |
|---|---|---|---|
| 火主燥 | **有** | YHZP-118-003 / 論疾病·火命段 | 「火主燥，面色紅赤」 |
| 皮膚枯燥 | **有** | YHZP-118-005 / 論疾病·金命段 | 「外則皮膚枯燥，瘋鼻赤疽癰皆膿血之咎」 |
| 皮膚乾燥 | **有** | YHZP-118-002（木命段）、YHZP-118-004（土命段） | 「外則皮膚乾燥，眼目之疾」 |

- 「火主燥」在**火命段**（火命见水及亥子旺地），「皮膚枯燥」在**金命段**（金命见火及巳午旺处）——两短语相隔一段，非连读一句。
- 维基文库对校：火命段「火主燥，面色红赤」一致；金命段「外则皮肤枯燥、疯鼻赤疽痈」一致。无版本异文。
- **查无**：无。三短语（火主燥 / 皮膚枯燥 / 皮膚乾燥）底本均确证存在。
