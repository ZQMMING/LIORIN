## 二、需立即修正（4 条，PATCH-001 明文强制）——**已于 2026-09-16 全部执行 ✅**

### 修正-1：`dts_effect_state` 补 CONDITIONAL / UNDETERMINED（§8 明文「必须增加」）✅

现状（enums.py DTSEffectState + registry 同步）：
```
effective / partially_effective / ineffective / blocked
```
PATCH 要求：
```
EFFECTIVE / PARTIALLY_EFFECTIVE / INEFFECTIVE / BLOCKED / CONDITIONAL / UNDETERMINED
```
动作：enums.py + enum_registry.json 同步补 2 值（版本 v1.8.0）。值定义：
- CONDITIONAL：效力成立但有条件依赖（如「伤官配印需身弱方有效」）
- UNDETERMINED：证据/规则不足以确定效力

### 修正-2：`dts_support_state` 补 EXCESSIVE / UNDETERMINED（§7 明文「至少允许」）✅

现状（enums.py DTSSupportState + registry 同步）：
```
NONE / WEAK / NORMAL / STRONG
```
PATCH 要求：
```
NONE / WEAK / NORMAL / STRONG / EXCESSIVE / UNDETERMINED
```
动作：同步补 2 值。值定义：
- EXCESSIVE：生扶过旺（生多为克，母慈灭子类）
- UNDETERMINED：无法确定

**注意区分**：`dts_cong_support_state`（NONE/HAS_SUPPORT/UNKNOWN）是 F-3 裁决的**从格专用**枚举，语义为「有无生扶」而非「强度」，保持不并入（符合 §7「由具体经典 Rule 授权」）；本修正只改通用 `dts_support_state`。
