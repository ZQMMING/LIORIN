## 1. 底本谱系（先厘清「几本书」）

本轮最重要的认识：**之前把《河洛真数》与《河洛理数》当成同一本书的两个传本，
是错的**。它们是**两部不同的书**，卦解文字重合度极低：

| 底本 | 性质 | 与本地数据的关系 |
|---|---|---|
| 《河洛真数》 | 陈抟述、邵雍撰，续修四库全书·天一阁本 | **本地数据的唯一来源**（diancang 网页转录） |
| 《河洛理数》 | 另一部书（清人撰），卦解体例相近 | **独立旁证**，非同源 |
| diancang.xyz | 《河洛真数》网页整理稿 | 本地切片的直接上游（`data/heluo/guajie_grab.py` 抓取） |
| 3door.org / Daum Cafe | 《河洛理数》卦解整理稿 | 旁证（两者同源，见 §3） |

**实测重合度**（去标点 + 繁简归一 + 10-gram）：

```
3door 全量 60262 个 10-gram，与本地共有 2332（3.9%）
损卦：60/1169（5.1%）   观卦：44/1065（4.1%）   未济卦：0/1198（0.0%）
```

→ 3% 的重合 = **不同书**，不能当作「同一本书的另一传本」互相校勘。

**另一个关键澄清**：本地 `heluo_engine/orig/易卦释义_*.txt` **不是 OCR 产物**，
而是 `guajie_grab.py` 直接抓 diancang 网页文本得到的**清本转录**。
所以「OCR 底本乱码」这个前提对这一组文件**不成立** —— 本地数据本身是干净的。

## 3. 六源对拍：3door / Daum 是同源，不构成两个独立证据

3door.org（cn.3door.org 为其简体版）与 Daum Cafe「[河洛理數] 六十四卦 原文」
在讹字上完全同源：

- 两者都把「己卯」写作「**已**卯」（形近误植）
- 两者都把「壬戌」写作「壬**戍**」（形近误植）
- 两者行文断句完全一致

→ 二者是同一整理稿的两个载体，**多数表决时只能算一票**。

## 5. 定量：京房标准重算 64 卦

以八纯卦纳甲（公开文献多源一致）+ 64 卦上下卦表重算「下卦内纳甲前 3 + 上卦外纳甲后 3」：

```
纳甲段(6条) == 京房标准：58/64
不一致 6 个：比、小畜、观、贲、损、夬
```

即 **58 卦与京房标准逐字一致**，6 卦例外，且 6 例全部有原典依据。

## 6. 顺带查出的引擎真缺陷：「借用」段被静默丢弃

旧解析正则在**第一个逗号**处截断：

```python
m = re.search(r"纳甲(?:是|有)[：:]?\s*([^，。；]{2,60})", text)
```

而原典的「借用」段前面正好跟一个逗号 ⇒ **「借用」干支从未进入引擎**。
（另有一处 `if "借用" in part: break` 双重保险，同样导致丢弃。）

实测 64 卦中 **28 卦**的卦头带「借用」段，共 **105 条**干支，此前全部丢失。

### 已做的修复（保守口径）

- `_parse_gua_header` 改为取到句号（跨逗号），再按「借用」切成两段；
- 新增 `GuaDuan.jieyong` 字段，**原典照录，不并入 najia**；
- 「年干支在纳甲本命」判定**口径不变**（原典从未解释「借用」语义，
  已检索全书影印本与网络清本，「借用」仅作为卦头格式出现，未见释义 ⇒ **无据不擅改**）；
- 但借用段在 `evidence` 中**显形披露**，不再沉默。

### 为什么比 / 小畜 / 夬 的外卦不并入 najia

影印本逐页核实：这三卦的「借用」段**后 3 条**恰是它们的外卦纳甲：

| 卦 | 借用段后 3 条 | 该卦外卦（京房标准） | 相符 |
|---|---|---|---|
| 比 | 戊申、戊戌、戊子 | 坎外卦 戊申、戊戌、戊子 | ✓ |
| 小畜 | 辛未、辛巳、辛卯 | 巽外卦 辛未、辛巳、辛卯 | ✓ |
| 夬 | 丁亥、丁酉、丁未 | 兑外卦 丁亥、丁酉、丁未 | ✓ |

这**可能是**原典的排版体例（纳甲段列内卦，借用段末位补外卦），
但**原典未作解释**，故仅**留档 + 加守卫**，**不改写 najia**。
若将来取得《河洛理数》侧或影印原页的进一步佐证，可另立据再议。

## 8. 本轮的方法论沉淀

1. **「本地是 OCR 底本」这个前提要先验证**。本项目 `guajie_raw/` 里的「易卦释义」
   实为网页清本转录，不是 OCR；搞错前提会一路错下去。
2. **同名不等于同书**。3door / Daum 表面是《河洛理数》，《河洛真数》另有其书；
   归一化后 10-gram 重合仅 3.9%，足以判定不同文本。
3. **同源的两个载体只算一票**（3door 与 Daum 共享同一讹字「已卯」「壬戍」）。
4. **差异要分三类**：本地失真 / 版本异文 / 原典体例。三类的处理完全不同，
   混为一谈就会「据公理擅改原典」。
5. **公理只能提示可能有讹，不能订正原典** —— 但**影印原页可以**。
   本轮正是靠影印页（第 241/322 页）把「原典不统一」翻成「版本异文」。
6. **静默丢弃比错值更危险**：本轮真正的 bug 不是某条纳甲算错，
   而是「借用」段 105 条数据被正则吞掉且无任何痕迹。
