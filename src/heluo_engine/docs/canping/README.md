## 一、参评秘诀辩（卷十开篇正文）

客有以河洛见访者，相与上下论议，谈及参评秘诀，乃曰：此数自图南传于邵氏，富贵贫贱吉凶祸福毫发不爽矣，今复以参评之说加之，宁不谓疣赘耶？予谢之曰：昔孟夫子不以好辩为得已，予于斯数敢以疣赘为讳耶？盖河图卦中有辞吉则吉者，有辞凶则凶者，此固易从易知；至于卦内有辞吉而理凶者，有辞凶而理吉者，此则由乎节气之浅深、爻位之当否，初学遇之如水月镜花，未易把捉，必以此数参评品备。庶哉如着裘者之挈其领、举纲者之提其网。看诸数内有金玉龙麟桂兰星斗之类，则为富贵子息之命；若数内有刀箭雪霜草云争斗空缺之类，则为贱寡孤克，非负则夭，或多宜非横祸。更数中多用故典，即须参考故典吉凶断之（如马陵书大字斗志有孙膑之类）。

## 二、参评例

一数有水火木金土之五部，不拘男女之命，各循其部而求之，斯无错误耳。
此数名目谨依皇极之例，以千百十零为定局，但彼则从右而左横下，今更而直下，盖欲学者便于观览。

假如水部参评中"二二三一"乃二千二百三十零一数也。其上层（月在二句）乃男子之命；其中层（年来二句）乃女人之命；其下层（酒醒二句）乃男女相共大运流年也。"二二三三"乃二千二百三十零三数：上层（月出二句）男子命；中层（要知二句）女人命；下层（定前二句）男女相共大运流年也。举此二数为例，余可类推。

- 中层女命数空无字者，乃贫贱夭折之命。
- 下层大运流年数空无字者，重者损寿，轻者破耗刑克；或空一二字者，即一二分之灾咎也。

## 三、起参评秘诀·金锁银匙歌（原文+注）

1. **阴阳俱用二千祖** —— 此句不论阴阳男女，八字所属干支，虚将二千之数先加于算盘千位上，为祖之谓也。
2. **日至生时百中数** —— 此句只就日时地支说，不用天干。假如戌日寅时生人，将日支戌字数至时支寅字：戌亥子丑寅，隔五个字，一个字准一百数，算五个字作五百数，将此五百数加于算盘百位上，连前虚加二千共成二千五百数也。且如申日申时生人，将日支申字数至时支申字：申酉戌亥子丑寅卯辰巳午未申，隔十三个字，一个字准一百数，十三个字作一千三百数，将此一千三百数加于算盘千位百位上，连前虚加二千共成三千三百数也。余仿此。
3. **时日皆从子上轮，十零本位月休睹** —— 此二句亦只就日时地支说，不用天干。假如前戌日寅时生人，先从子字轮起至日支戌字：子丑寅卯辰巳午未申酉戌，隔十一个字，一字准一数，十一字记十一数；再从子字轮起至时支寅字：子丑寅，隔三个字，一字准一数，三字记三数。日时二支所得共十四数：以十数加于算盘十位上，以四数加于算盘零位，谓之"十零本位"，连前二千五百共成二千五百一十四数也。且如前申日申时生人，先从子字轮起至日支申字：子丑寅卯辰巳午未申，隔九个字记九数；再从子字轮起至时支申字：子丑寅卯辰巳午未申，隔九个字记九数。日时二支所得共十八数：以十数加于算盘十位上，以八数加于算盘零位，连前三千三百共成三千三百一十八数也。其曰"月休睹"者，谓此数只以日时为主，不用月令干支也。
4. **岁君水火廿七加** —— 此句就当生年上纳音说。假如前戌日寅时生人，生年是乙卯而乙卯年纳音属水，前数二千五百一十四加二十七数，共得二千五百四十一数也。且如前申日申时生人，生年是戊午而戊午年纳音属火，前数三千三百一十八加二十七数，共得三千三百四十五数也。若生年纳音不是水不是火者，不加二十七数也。
5. **木金虚度五十土** —— 其曰"木金虚度"者，谓当生年上纳音属木属金者不必加数也；其曰"五十土"者，谓当生年上纳音属土则加五十数是也。
6. **再将一二三四五，配却水火木金土** —— 此二句亦就年上纳音说。如年纳音属水则配以一数加之，年上纳音属火则配以二数加之，年上纳音属木则配以三数加之，年上纳音属金则配以四数加之，年上纳音属土则配以五数加之。假如前戌日寅时生人，生年是乙卯而乙卯纳音属水，前数二千五百四十一加一数，共得二千五百四十二数是也。且如前申日申时生人，生年是戊午而戊午纳音属火，前数三千三百四十五加二数，共得三千三百四十七数是也。
7. **得策寻纳看当生**（策即数也，纳即纳音）—— 此句谓八字之数算毕，看得数上千上几百、十上几十、零数几个，然后寻当生年上纳音水火金木土五部，依其纳音所属之部而寻之便是。假如前乙卯生人纳音属水而总数得二千五百四十二，故即于水部去寻"二五四二"，其诗曰"掌中秋月扇，举动好风生，此是武将格"。且如前戊午生人纳音属火而总数得三千三百四十七，故即于火部去寻"三四七"，其诗曰"鸿毛草上风，阴阳互寒暑是也"。
8. **时日顺冲还共语**（冲即逆也）—— 此一句因前"日至生时百中数"句之尚欠详备，故再言此以发明之。盖由此数顺数有一个，逆数有一个，其诗有四句者有两句者。假如前戌日寅时生人，先以顺数故满五个字作五百算矣；若以逆数则从时支寅字至日支戌字：寅卯辰巳午未申酉戌，隔九个字，九字当九百数，则除前数中五百，数复以九百数加之，则为二千九百四十二，亦于水部去寻"二九四二"，其诗曰"玉壶无别物，赤蚁聚蜂屯"是也。且如前申日申时生人，顺逆俱得一千三百数，其诗同。且或有顺有逆无者，或逆有顺无者，不可执泥。

## 四、起大运例

- **阴阳俱用二千同** —— 此句谓起大运之法与起八字法一般，俱虚用二千于算盘上为祖。
- **只将大运替时轮** —— 此句谓起大运无别方法，只将人八字时支弃去不用，以大运地支逐运对日地支算便是。
- **其余一一依前例，万命堪凭断吉凶** —— 所谓一一依前例者，谓起运之法句句照金锁银匙歌打算，如起八字法一般，看得数多少，于水火木金土纳音运部寻之便是。

## 五、起流年例

- **流年之法是何如，千上同前自不殊** —— 此二句亦只说与虚加二千祖之法一般。
- **只把日支对太岁，替却日时一例推** —— 此二句谓不用日时地支打算，只将流年太岁地支与大运地支，句句依金锁银匙之法推算，看数多少，亦于水火木金土纳音五部运内寻之便是。

## 七、与主链关系

- 参评为**独立大定数体系**（皇极经世之例，千百十零定局），与卦爻断主链（先天/后天/元堂/判词）**两套玩法**，故独立建档、独立模块，不混入 `guajie.py` 主链输出。
- 主链断命用卦爻；参评断命用"数内取象"（金玉龙麟桂兰星斗=富贵子息命；刀箭雪霜草云争斗空缺=贱寡孤克）。二者可互参，不作互相覆盖。
