### 7.2 规则解读

河图十数中**奇数（1,3,5,7,9）为天位、偶数（2,4,6,8,10）为地位** ——
故「奇左下／偶右下」= **奇数归天数、偶数归地数**。
天干各配**一个**河图数（L41-L44），地支各配**两个**（L47-L51）。
四柱天地二数 = 每柱「干值 + 支的两个值」**全部按数值奇偶**分：
**奇数之和为天数，偶数之和为地数。**

引擎 `numbers.py` 的 `STEM_VALUES`／`BRANCH_VALUES`／`compute_tian_di_shu`
正是这一口径（唯一差别：引擎支值存**数值升序**，如巳午存 `(2,7)`，
而原典写「地二…天七」—— 语义等价、存储顺序不同）。

## 九、2026-10-22 补：起月卦「双月取应爻」的应爻基准裁定（读法 B）

### 9.1 疑点

L124「凡起月卦，就年卦中前一位起，单月变爻，双月变应爻」与
L126「又假如小象是泰卦九二，卦应爻居五，双月取应爻」——
「应爻」的基准未言明，按字面可作两解（差一个爻位）：

- **读法 A**：以**元堂**（年卦流年爻）为基准 → 双月恒取 元堂+3
- **读法 B**：以**当月阳月的居位变爻**为基准 → 双月取 居位+3

### 9.2 判决证据（《河洛理数》卷五「月卦」，四组显式对拍）

| 原文 | 阳月居位 | 双月所取 |
|---|---|---|
| 「五月是小畜三爻，六月则取小畜应爻上九」 | 三爻 | 上爻 |
| 「七月是乾九四，八月则取乾卦应爻初九」 | 四爻 | 初爻 |
| 「……大有六五……取大有应爻……离卦六二」 | 五爻 | 二爻 |
| 「十一月是大壮上爻，则十二月取大壮应爻……归妹六三」 | 上爻 | 三爻 |

底本：K3-448 修正版 L469-L471；K3-447 修正版 L1132-L1146。
四组一致指向**读法 B**，且该链阳月居位序 = 上爻 → 初、二、三、四、五、上
（即元堂 + 1…+6）。读法 A 会使六个月双月同变一爻，与实证冲突。

同书互证：《河洛真数》起时卦例「日卦变时卦，与年卦变月卦同……子时其应爻则丑时也」
——「其应爻」取**刚变之爻**的隔三位，与读法 B 同基准。

### 9.3 L126 泰例的落位

泰卦元堂九二 → 阳月居位 = 三、四、五、上、初、**二** → 十一月居位九二 →
**十二月双月**取九二之应爻 = 1+3 = **4（五爻）**，与「卦应爻居五，双月取应爻」吻合 ✓
