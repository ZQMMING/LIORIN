## 一、问题（以下为**已被推翻的原始记录**，保留作决策留痕）

`c2b112f2` 依原典四条明文，在纯卦分支钉了 4 卦 × 子卯/午酉 = 8 处锚点，
但丑寅辰巳未申戌亥 8 个时辰仍走 `hour_idx % 6` 旧线性兜底，形状不自洽：

```
男乾  子0 丑1 寅2 卯0 辰4 巳5 午2 未1 申2 酉2 戌4 亥5
              ↑子卯同位(重数)      ↑午酉同位
      但丑夹在子卯之间成 1 —— 这不是「重数」的形状
```

「重数」既已成立（同爻被两个时辰各数一次），就不该只对 4 个时辰成立、对其余 8 个失效。

## 二、「重数」的释义（据原典本节自释）

原典 L294 紧接本节首句：

> 夫乾坤乃大易之门户……当求师旨之明……
> **又一本云，乾坤二卦，安元堂爻位，当依羲皇三画卦立身，与文王后天六画卦不同。**

「依羲皇三画卦立身」「与文王六画卦不同」——**重数即三画变六画**：
三画（三爻）重数一遍成为六画，故**一个三爻卦配六个时辰，三爻走两轮**。

### 分组

原典把十二时写成「**子卯二时**」「**午酉二时**」两两成对，
卯距子三、酉距午三，正是「三爻走两轮」后回到头爻的时辰 —— 与机制自洽：

- 阳时组（子丑寅卯辰巳）先数
- 阴时组（午未申酉戌亥）后数
- 各配一卦

### 方向

| 方向 | 阳时组 | 阴时组 |
|---|---|---|
| 自下而上 | 重数下卦：初·二·三 各两轮 | 重数上卦：四·五·上 各两轮 |
| 自上而下 | 重数上卦：上·五·四 各两轮 | 重数下卦：三·二·初 各两轮 |

## 四、唯一失配处的裁决：男乾「午酉三爻」→「四爻」

这是**原典自身矛盾**，不是推导失误。三条独立理由：

1. **同配置互证**：男乾与女坤是完全相同的配置
   （纯卦 · 自下而上 · 阳时组重数下卦 · 阴时组重数上卦），
   差异只在卦的阴阳与男女。原典女坤条明文作「**午酉二时皆在四爻**」。
   同一配置不可能一作三、一作四。

2. **机制排他**：「重数上卦」限定该组只能落四·五·上三爻。
   **三爻属下卦**，与「重数上卦」自相矛盾。
   女乾/男坤两条的「三爻」不矛盾，因为那两条阴时组走的是「重数下卦」，
   自上而下时下卦首爻正是三爻。

3. **行 315 自认待详**：男坤条末「宜更详之」，编者已对整节存疑。

**裁决：男乾条之「三」为形近涉笔之讹，取「四」。**

本轮对原典取值的改动**仅此一处**。

## 五、旁证：与本仓库杂卦既有实现同构

杂卦 N=3（三阳/三阴）分支早已在用同一「三爻走两轮」语义：

```python
# yuan_tang.py 杂卦分支
target_idx = (candidates * 2)[t % 6]     # → [0,1,2,0,1,2]
```

N=1 分支「子丑或午未二时同在此爻」、N=2 分支「重数两次往复（四时）」
也是同一族语义。纯卦此前只是**没有套用**这套已存在的口径。
