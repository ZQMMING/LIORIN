## 2. 河洛侧已备好的出口

```python
from tongshu.engines.heluo.canonical_signals import build_platform_signals
signals = build_platform_signals(result)   # result: HeluoResult
```

产出 `list[dict]`，每项**严格是平台 `HeluoAdapter` 期望的形状**：

```python
{
  "gua": "风火家人",            # 卦名（引擎内部全名）
  "yao": 4,                     # 爻位序号 1..6
  "position": "九五",           # 爻名
  "shi": "有孚挛如，无咎。；……",  # 原典爻辞 + 叶吉/不叶断语（原文）
  "strength": 0.5,              # 沿用平台默认（河洛不建模强度）
  "temporal_scope": {"start_year": 1150, "end_year": 1150,
                     "granularity": "YEARLY"},
  # 可追溯附加字段（平台忽略）：
  "layer": "CYCLE_CONTEXT",     # BASELINE / CYCLE_CONTEXT / DAILY_ACTIVATION
  "source_engine": "Heluo",
  "strength_source": "platform_default(0.5)：河洛侧未建模强度",
}
```

四条层：**本命基线 / 流年周期 / 流月激活 / 流日激活**。

**边界（刻意不做）**：不发明事件本体 id（17 类 USO 本体不在河洛包内）、
不臆造强度、不替平台判方向（吉凶方向由平台 `normalize_heluo` 按文本关键词判定）。

守卫：`tests/heluo/test_heluo_canonical_signals.py`（6 条）—— 字段名与类型、
爻名与爻位序号自洽、强度恒为 0.5 且注明来源、断语可回查原典 64 卦逐爻数据、
无判词不产出。
