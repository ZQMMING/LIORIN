## 疑点一　阳月令 / 阴月令判定　🔴 确认错误

### 代码（`guajie.py:629`）

```python
yang_month = birth_month in (1, 2, 3, 4, 5, 6)  # 春夏季为阳月（简化，原典按节气细分）
```

### 原典依据（L854–L914，十二月卦气表）

原典对每个节气月都明写了卦气归属与阴阳消长，**不需要推断，只需读表**：

| 月 | 节气 | 卦气 | 原典自述 | 阴阳 |
|---|---|---|---|---|
| 正月 | 雨水 | 泰 | 「三阳出于寅，三阳至而大道成…小往大来，阴阳交畅」 | 阳 |
| 二月 | 春分 | 大壮 | 「四阳生于卯，四阳盛壮，帝出乎震」 | 阳 |
| 三月 | 谷雨 | 夬 | 「五阳生于辰，其卦为夬，刚决柔也」 | 阳 |
| 四月 | 小满 | 乾 | 「六阳终于巳，其卦为乾，乃**纯阳之月**」 | 阳（极） |
| 五月 | 夏至 | 姤 | 「**一阴始生于午**」 | 阴（起点） |
| 六月 | 大暑 | 遁 | 「二阴生于未，其卦为遁。二阴既长」 | 阴 |
| 七月 | 处暑 | 否 | 「三阴生于申，其卦为否。三阴既长」 | 阴 |
| 八月 | 秋分 | 观 | 「四阴生于酉，四阴既长，是名观卦」 | 阴 |
| 九月 | 霜降 | 剥 | 「五阴生于戌，五阴长而阳剥落」 | 阴 |
| 十月 | — | 坤 | 「六阴生于亥…乃**纯阴之时**」 | 阴（极） |
| 十一月 | 冬至 | 复 | 「**一阳生于子**…阳气始生，阴道渐消」 | 阳（起点） |
| 十二月 | 大寒 | 临 | 「二阳生于丑，其卦为临」 | 阳 |

**故**：
- **阳月令 ＝ 十一月、十二月、正月、二月、三月、四月**（冬至一阳生 → 小满六阳俱备）
- **阴月令 ＝ 五月~十月**（夏至一阴生 → 十月六阴俱纯）

### 比对结果：4 个月判反

| 月 | 代码 | 原典 | |
|---|---|---|---|
| 1~4月 | 阳 | 阳 | ✓ |
| **5月** | **阳** | **阴** | ✗ 夏至一阴始生 |
| **6月** | **阳** | **阴** | ✗ 二阴既长 |
| 7~10月 | 阴 | 阴 | ✓ |
| **11月** | **阴** | **阳** | ✗ 冬至一阳生于子 |
| **12月** | **阴** | **阳** | ✗ 二阳生于丑 |

**5、6、11、12 四个月全错**，其中 11、12 月属「冬至一阳生」的阳令被判成阴月。

### 交叉验证（原典自身其它条文，四条独立佐证）

1. **L872**「**三四月阳数当健之时**，阳数不足，阴数有余，谓之上逆天令」→ 三四月属阳 ✓
2. **L869**「**三月谷雨后**，阳数太多，而阴数不足，无妨」→ 三月属阳 ✓
3. **L872**「如**夏至阴生**，至处暑前后，三阴正长，君子道否之时」→ 五月属阴 ✓
4. **L714**「男命**阳月生者，冬至以后，雨水前**，天数不及二十五…」→ 十一月冬至属阳 ✓

### 影响面

`judge_shu_xiong()` 是**生产链路**函数（`build_guajie_from_result` L948 调用），
决定 `shu_xiong`（数凶）是否为真，进而影响 `compose_guajie` 的综合判词与生死大凶断。

原典依据 **L1073**：「以弱敌强…**阴月令逢之，尚庶几，阳月令逢之，必主灭顶之凶。**」
—— 阳月令遇之才凶，阴月令尚可。代码把 5、6 月误判为阳月令（会误判凶），
把 11、12 月误判为阴月令（会漏判凶）。**两个方向都错，且都影响生死断。**

### 处置建议

改为按原典十二月卦气表判定，并保留表本身作为守卫数据：

```python
# 原典 L854–L914：阳气自十一月冬至一阳生，至四月小满六阳俱备（纯乾）；
# 阴气自五月夏至一阴生，至十月六阴俱纯（纯坤）。
_YANG_YUE_LING = frozenset({11, 12, 1, 2, 3, 4})
yang_month = birth_month in _YANG_YUE_LING
```

属 P0（影响生死断），**待用户批准后实施**。

## 疑点二　节候卦：原典的「节卦」与「七十二候」体系完全缺失　🟠 大范围缺失

### 原典（L1489–L1492，整节「节候卦爻」）

> **气之八节，总之其卦四，候有七十二，细分之，其卦六十。**
> **节卦**坎初六起冬至，九二小寒，六三大寒，六四立春，九五雨水，上六惊蛰。
> **震**初九起春分，六二清明，六三谷雨，九四立夏，六五小满，上六芒种。
> **离**初九起夏至，六二小暑，九二大暑，九四立秋，六五处暑，上九白露。
> **兑**初九起秋分，九二寒露，九三霜降，九四立冬，九五小雪，上六大雪。
> **每卦总管九十日，自下而上，每一爻各直十五日。**
>
> **候卦**颐四爻起冬至蚯蚓结，中孚三爻麋角解，复二爻水泉动，屯初爻小寒雁北乡…

这一段给出**三张完整表**：

1. **节卦表（4×6＝24 爻位）**：坎起冬至、震起春分、离起夏至、兑起秋分，
   每卦 90 日、六爻各直 15 日。
2. **七十二候表（72 条）**：每候一个卦 + 一爻 + 一个物候名
   （如「颐四爻起冬至**蚯蚓结**」）。
3. 卦数关系：八节 → 其卦四；七十二候 → 细分；卦六十。

### 代码现状（`jiehhou.py`）

- 实现的是 **24 节气 → (起始卦, 动爻, 结果卦)** 的映射，
  来源注释写「卦气歌原文解读（中华典籍网）」——**这是另一套体系**
  （京房卦气说的节气配卦），**不是**原典 L1492 的「节卦」表。
- **七十二候：全仓零实现**（grep `七十二|蚯蚓结|东风解冻|桃始华` 仅命中
  其他引擎的无关代码）。
- 节卦表亦无。

### 交叉验证

节卦表与七十二候表**内部自洽且互相印证**：
- 节卦「坎初六起冬至」↔ 候卦「颐四爻起冬至」——同一节气两个体系的起点，
  一为坎卦之初六、一为颐卦之四爻，爻位互补，可交叉校验。
- 七十二候首条「蚯蚓结」正是《月令》七十二候「冬至蚯蚓结」的标准写法 ✓
- 「东风解冻」「桃始华」「鹰乃祭鸟」等同为《月令》标准候名 ✓

### 影响面与定夺

- 节候卦 H11 当前「366/366 天可取」是**基于卦气歌那套**实现的，
  本身自洽可用；但它**不是**原典 L1492 的口径。
- 原典此节是否要求替换现有实现，还是作为**并列的第二套体系**补充
  （节卦／候卦 vs 卦气歌），属**规则裁决**，**须用户定夺**，我不擅自改。

## 疑点三　「归妹直为兑九五」中的「直为」　🟡 待考，不影响实现

### 现象

识典古籍影印本《河洛真數》流月卦例作：
「五月變歸妹**直為**兑九五」「七月變兑上六爲履上九」。

本地转录该处如何作，需逐字比对。**「直为」二字生涩**，
疑为「**变**为」之讹，或「直」为「即」之音近。

**不影响任何实现**（流月卦例不在生产链路上），
但影响日后做「起例卷中/下对照表」时的**原文录入准确性**，登记待考。
