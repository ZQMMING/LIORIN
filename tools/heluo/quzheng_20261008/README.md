## 取证纪律

1. **四本一致才认**；不一致才可能是讹。
2. 不一致时，再看**哪一读能与本段其余条文自洽**。
3. **自校验优先于「读起来像对」**——L507 取「巳」不是因为看着顺，
   而是因为「反者干支 == 对宫干支组」这条机械校验只有「巳」能过。
4. 原典**自陈并列两说**时（L519「又云」），两说并存、不得择一。
